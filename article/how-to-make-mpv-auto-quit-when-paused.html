How to Make mpv Auto Quit When Paused

This guide explains how to automatically close the mpv media player when playback remains paused for a designated period. Because mpv does not have a native configuration flag for pause timeouts, this behavior is achieved using a lightweight Lua script that monitors the pause state, starts a countdown timer, and sends a quit command if the timer expires before playback resumes.

Step 1: Locate or Create Your mpv Scripts Directory

mpv looks for user scripts inside a dedicated scripts folder located within its configuration directory. If the directory does not exist, create it manually:

  • Linux / macOS: ~/.config/mpv/scripts/
  • Windows: %APPDATA%\mpv\scripts\ (or portable_config\scripts\ if using portable mode)

Step 2: Create the Lua Script

Inside the scripts directory, create a new file named auto_quit_on_pause.lua. Open it with any plain text editor and paste the following code:

-- Duration in seconds before quitting (e.g., 300 = 5 minutes)
local TIMEOUT = 300

local timer = nil

local function on_pause_change(name, value)
    if value == true then
        -- Playback paused: Start countdown timer
        timer = mp.add_timeout(TIMEOUT, function()
            mp.command("quit")
        end)
    else
        -- Playback resumed: Cancel active timer
        if timer then
            timer:kill()
            timer = nil
        end
    end
end

mp.observe_property("pause", "bool", on_pause_change)

Step 3: Customize the Timer

Modify the TIMEOUT variable at the top of the script to change the threshold:

  • Set to 60 for 1 minute.
  • Set to 300 for 5 minutes.
  • Set to 900 for 15 minutes.

Save and close the file.

Step 4: Verify the Setup

  1. Open a video or audio file with mpv.
  2. Press the spacebar to pause playback.
  3. Wait for the designated duration.

mpv will automatically exit as soon as the timeout finishes. If you press the spacebar again to resume playback before the time runs out, the timer cancels immediately and playback continues normally.
