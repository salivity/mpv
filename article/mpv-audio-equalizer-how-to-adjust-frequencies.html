mpv Audio Equalizer: How to Adjust Frequencies

While the mpv media player does not include a traditional graphical equalizer by default, it does have built-in capabilities to adjust audio frequencies during playback. Instead of relying on a visual slider interface, mpv leverages FFmpeg's powerful audio filtering libraries under the hood. Users can adjust bass, treble, or full multi-band frequency ranges in real time using command-line arguments, keybindings in configuration files, or community-developed Lua scripts.

How mpv Handles Frequency Adjustments

mpv delegates audio processing to FFmpeg’s libavfilter. This means any equalization filter supported by FFmpeg can be applied directly to an audio stream during playback. Because mpv prioritizes a minimalistic, keyboard-driven interface, these adjustments are typically controlled through commands rather than visual menus.

Using FFmpeg Filters via the Command Line

To apply an equalizer when launching a file, use the --af (audio filter) option. FFmpeg provides several equalizer filters, such as equalizer for single bands and firequalizer for multi-band adjustments.

For example, to boost the 1000 Hz frequency by 5 dB with a bandwidth of 200 Hz:

mpv --af=lavfi=[equalizer=f=1000:width_type=h:width=200:g=5] "video.mp4"

To create a basic 3-band equalizer (adjusting lows, mids, and highs), chain multiple filters together:

mpv --af=lavfi=[equalizer=f=64:t=q:w=1:g=3,equalizer=f=1000:t=q:w=1:g=0,equalizer=f=8000:t=q:w=1:g=4] "video.mp4"

Real-Time Adjustments with input.conf

To change frequency levels during playback, map keys in your input.conf file to dynamically modify filter properties.

You can bind keys to toggle or cycle through equalizer presets. For example, add the following lines to your input.conf to quickly toggle a bass boost:

b af toggle lavfi=[equalizer=f=60:t=q:w=1:g=6]

Pressing b during playback will instantly apply or remove the 6 dB boost at 60 Hz.

Adding a Visual Interface

Users who prefer visual sliders over terminal commands can install community-made Lua scripts, such as mpv-equalizer. Placing these scripts in the mpv scripts directory adds an on-screen display (OSD) equalizer that can be manipulated using standard keyboard shortcuts or mouse clicks during playback. Alternatively, GUI front-ends built on top of mpv—such as SMPlayer or IINA—include visual graphic equalizers out of the box.
