View Active Video and Audio Filters in mpv

This guide explains how to view all currently active video and audio filters applied to playback in the mpv media player. You can inspect your active filter chains in real time using built-in statistics screens, the interactive command console, or by configuring custom On-Screen Display (OSD) keybindings.

Method 1: Using the Built-In Statistics Overlay

The fastest way to view active filters without modifying configuration files is through mpv's built-in stats script.

  1. While a video is playing, press Shift + I (uppercase I) to open the persistent stats overlay.
  2. Press 1 or 2 on your keyboard to switch between pages:
    • Page 1 displays general file and decoder details, including applied hardware decoding and basic filter information.
    • Page 2 displays the full video and audio processing pipelines, showing the precise order of active filters (vf and af).
  3. Press Shift + I again or Escape to close the overlay.

Method 2: Inspecting Filters via the Interactive Console

mpv features a built-in terminal console that lets you query active player properties instantly.

  1. Press the grave accent / tilde key (` or ~) to open the console overlay.
  2. Type the following command to print the active video filters: 
    print-text ${vf}
  3. Type the following command to print the active audio filters: 
    print-text ${af}
  4. If filters are active, the console will print their names and parameters (for example, sub,lavfi=[crop=1920:800:0:140]). If no filters are applied, the output will return empty brackets [].

Method 3: Adding Custom OSD Keybindings

If you frequently toggle filters and want quick visual confirmation on screen, you can map dedicated keys to print the filter chains to the OSD.

Open your input.conf file (located in ~/.config/mpv/ on Linux/macOS or %APPDATA%/mpv/ on Windows) and add the following lines:

# Display active video and audio filters on the OSD
Alt+v show-text "Video Filters: ${vf}"
Alt+a show-text "Audio Filters: ${af}"

Pressing Alt + v will display a temporary banner showing the current video filter list, while Alt + a will display the active audio filter list.

Method 4: Terminal and IPC Properties

If you run mpv from a command line or control it via an IPC socket, you can monitor the properties directly:

  • Terminal Verbosity: Run mpv with increased filter logging: 
    mpv --msg-level=vf=v,af=v filename.mkv
  • IPC Socket: Query the properties vf and af over JSON IPC: 
    { "command": ["get_property", "vf"] }
