How to Enable Exclusive WASAPI in mpv on Windows

Enabling exclusive WASAPI mode in mpv allows you to bypass the Windows audio mixer, preventing unwanted resampling, software mixing, and alterations to the original audio stream. This guide explains how to configure mpv's configuration file to achieve bit-perfect audio playback through your designated digital-to-analog converter (DAC) or sound card.

Step 1: Locate or Create the mpv Configuration File

To apply permanent settings to mpv, you must edit its configuration file:

  1. Press Win + R, type %APPDATA%\mpv, and press Enter.
  2. If the folder does not exist, create it.
  3. Inside this directory, locate the file named mpv.conf. If it does not exist, create a new text file and rename it to mpv.conf (ensure the file extension is .conf and not .txt).
  4. Note for portable installs: If you use a standalone portable version of mpv, create or edit mpv.conf inside the portable_config folder within your main mpv directory.

Step 2: Identify Your Audio Device (Optional but Recommended)

While mpv can output to your default audio device, specifying your exact hardware prevents issues when switching playback endpoints:

  1. Open Command Prompt or PowerShell.
  2. Run the command: 
    mpv --audio-device=help
  3. Locate the wasapi entries corresponding to your audio interface or DAC (e.g., wasapi/{0.0.0.00000000}.{GUID}). Copy the exact device string.

Step 3: Configure mpv for Exclusive WASAPI Output

Open your mpv.conf file in a text editor like Notepad and add the following lines:

# Set the audio output driver to WASAPI
ao=wasapi

# Enable exclusive mode (bypasses Windows audio mixer)
audio-exclusive=yes

# Prevent mpv from downmixing or dropping audio channels
audio-channels=stereo,5.1,7.1

# Optional: Specify your exact device found in Step 2
# audio-device=wasapi/{YOUR-DEVICE-IDENTIFIER}

Step 4: Ensure Bit-Perfect Audio Settings

Exclusive mode provides the pathway, but you must also prevent mpv's internal engine from altering the audio:

  1. Keep mpv's internal volume set to 100% to prevent digital attenuation.
  2. Avoid using audio filters, equalizers, or software normalization options such as loudnorm.
  3. Do not set fixed values for audio-samplerate or audio-format, as leaving them unset ensures the audio stream is passed to your DAC at its native sampling rate and bit depth.

Step 5: Verify Playback

  1. Launch a media file using mpv.
  2. Press Shift + I to open mpv’s internal playback statistics.
  3. Navigate to the audio section using the arrow keys or the 2 key.
  4. Verify that the output format, sample rate, and channels precisely match the input source.
  5. Confirm that other system sounds (such as YouTube in a browser or Windows notifications) are muted while mpv is playing, which indicates that exclusive mode is functioning properly.
