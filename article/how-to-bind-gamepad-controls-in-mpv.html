How to Bind Gamepad Controls in mpv

This guide explains how to configure a gamepad or video game controller to control playback and navigate menus in the mpv media player. By leveraging mpv's native SDL2 game controller integration, you can identify input names, create an input.conf file, and assign buttons and analog axes to media commands like seeking, volume control, pausing, and on-screen interface navigation.

1. Locate or Create the input.conf File

mpv reads custom controls from an input.conf file inside its configuration directory. If this file does not exist, create a plain text file named input.conf in the appropriate path for your operating system:

  • Linux / macOS: ~/.config/mpv/input.conf
  • Windows: %APPDATA%\mpv\input.conf (or inside a portable_config folder in the same directory as mpv.exe)

2. Identify Gamepad Button and Axis Names

mpv uses standard SDL gamepad naming conventions. To discover the exact names mpv assigns to your controller's inputs, run mpv in input-test mode via the terminal or command prompt:

mpv --input-test --force-window

Press any button or tilt the analog sticks while the test window is focused. The console output will display the exact identifier for each input (e.g., GAMEPAD_START, GAMEPAD_ACTION_DOWN, GAMEPAD_LEFT_STICK_X).

Common input names include:

  • D-Pad: GAMEPAD_DPAD_UP, GAMEPAD_DPAD_DOWN, GAMEPAD_DPAD_LEFT, GAMEPAD_DPAD_RIGHT
  • Left Stick: GAMEPAD_LEFT_STICK_UP, GAMEPAD_LEFT_STICK_DOWN, GAMEPAD_LEFT_STICK_LEFT, GAMEPAD_LEFT_STICK_RIGHT
  • Face Buttons: GAMEPAD_ACTION_DOWN (A/Cross), GAMEPAD_ACTION_RIGHT (B/Circle), GAMEPAD_ACTION_LEFT (X/Square), GAMEPAD_ACTION_UP (Y/Triangle)
  • Shoulder Buttons: GAMEPAD_LEFT_SHOULDER (LB/L1), GAMEPAD_RIGHT_SHOULDER (RB/R1)
  • Triggers: GAMEPAD_LEFT_TRIGGER (LT/L2), GAMEPAD_RIGHT_TRIGGER (RT/R2)
  • Menu Buttons: GAMEPAD_START, GAMEPAD_BACK (Select/Share)

3. Add Keybindings to input.conf

Open your input.conf file in a text editor and define actions using the format: [INPUT_NAME] [COMMAND].

Essential Playback Controls

GAMEPAD_ACTION_DOWN    cycle pause           # A / Cross: Play/Pause
GAMEPAD_ACTION_RIGHT   quit                  # B / Circle: Close mpv
GAMEPAD_ACTION_UP      cycle fullscreen      # Y / Triangle: Toggle Fullscreen
GAMEPAD_START          cycle pause           # Start: Play/Pause

Seeking and Volume Control

GAMEPAD_DPAD_LEFT      seek -5               # D-Pad Left: Seek back 5 seconds
GAMEPAD_DPAD_RIGHT     seek 5                # D-Pad Right: Seek forward 5 seconds
GAMEPAD_DPAD_UP        add volume 2          # D-Pad Up: Raise volume
GAMEPAD_DPAD_DOWN      add volume -2         # D-Pad Down: Lower volume

GAMEPAD_LEFT_SHOULDER  add chapter -1        # LB: Previous chapter
GAMEPAD_RIGHT_SHOULDER add chapter 1         # RB: Next chapter
GAMEPAD_LEFT_TRIGGER   seek -30              # LT: Rewind 30 seconds
GAMEPAD_RIGHT_TRIGGER  seek 30               # RT: Fast-forward 30 seconds

Navigating the Interface (OSD and Menus)

To navigate mpv's On-Screen Controller (OSC) or user scripts (such as file browsers or playlist menus), map the analog stick or directional buttons to standard menu navigation commands:

GAMEPAD_LEFT_STICK_UP    script-binding osd/up      # Menu Up
GAMEPAD_LEFT_STICK_DOWN  script-binding osd/down    # Menu Down
GAMEPAD_LEFT_STICK_LEFT  script-binding osd/left    # Menu Left
GAMEPAD_LEFT_STICK_RIGHT script-binding osd/right   # Menu Right
GAMEPAD_ACTION_DOWN      script-binding osd/select  # Confirm selection
GAMEPAD_ACTION_RIGHT     script-binding osd/back    # Back / Cancel

If you only use the default interface without custom menu scripts, you can map the stick directly to interface feedback commands:

GAMEPAD_LEFT_STICK_UP    show-progress              # Display timeline
GAMEPAD_BACK             show-text "${playlist}"    # Display playlist on screen

4. Adjust Deadzones (Optional)

If your analog sticks trigger actions unintentionally due to drift, configure the deadzone setting in your mpv.conf file:

input-gamepad-deadzone=0.2

This sets a 20% deadzone threshold, ensuring that minor analog stick movements are ignored until pushed past the specified value. Save both configuration files and relaunch mpv to apply your changes.
