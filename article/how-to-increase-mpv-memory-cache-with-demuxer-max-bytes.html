How to Increase MPV Memory Cache with Demuxer-Max-Bytes

This article explains how to increase the playback cache size in the mpv media player using the demuxer-max-bytes option. By adjusting this setting, you can allow mpv to store more video data ahead of time in your system RAM, preventing stuttering and buffering issues when streaming over a network or playing high-bitrate media files. You will learn how to configure this parameter both temporarily via the command line and permanently in your configuration file.

Understanding demuxer-max-bytes

The demuxer-max-bytes setting dictates the maximum amount of RAM the player’s demuxer can use to buffer packets ahead of the current playback position. By default, mpv allocates a relatively conservative cache size (typically around 150 MiB for network streams). If your network fluctuates or you are playing very large files, this default may be depleted faster than it can refill.

Values can be specified in standard units such as KiB, MiB, or GiB. For example, 1024MiB or 1GiB allocates one gigabyte of RAM for the read-ahead buffer.

Method 1: Permanent Configuration via mpv.conf

To apply the cache size automatically every time mpv starts, add the setting to your configuration file.

  1. Locate or create your mpv.conf file:

    • Linux/macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config folder if using a portable build).

  2. Open the file in a text editor and add the following line:

demuxer-max-bytes=1GiB

You can replace 1GiB with your preferred size, such as 500MiB or 2GiB, depending on your available system memory.

  1. Optional: If you also want to keep previously played content in the cache for faster backward seeking, you can set the back-buffer size as well:
demuxer-max-back-bytes=500MiB
  1. Save and close the file.

Method 2: Temporary Use via Command Line

If you only need to increase the cache for a specific stream or file, you can pass the option directly when launching mpv from the terminal or command prompt:

mpv --demuxer-max-bytes=1GiB "https://example.com/stream.mkv"

For local files:

mpv --demuxer-max-bytes=1GiB "video.mkv"

Verifying the Cache

To confirm that the cache is working during playback:

  1. Press Shift + I while playing a video to open the mpv statistics overlay.
  2. Press 2 to view the frame timings and cache details.
  3. Look for the Cache section, which displays the current buffer size in seconds and megabytes alongside your configured maximum limit.
