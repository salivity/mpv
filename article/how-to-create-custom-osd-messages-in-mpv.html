How to Create Custom OSD Messages in mpv

You can define custom On-Screen Display (OSD) messages to appear when pressing macro keys or shortcuts in the mpv media player. This functionality is configured directly inside your input.conf file using the built-in show-text command. It allows you to display purely informational messages, chain custom alerts to specific player functions, or output real-time dynamic properties like volume and playback speed.

1. Locate or Create input.conf

To bind custom keys and messages, open or create the input.conf file in your mpv configuration directory:

  • Linux / macOS: ~/.config/mpv/input.conf
  • Windows (standard): %APPDATA%/mpv/input.conf
  • Windows (portable): portable_config/input.conf in the mpv directory

2. Display a Simple Custom Message

Use the show-text command followed by the text string you want to display on the screen when a key is pressed.

F1 show-text "Macro 1 triggered"

You can optionally specify how long the message stays on screen by adding the duration in milliseconds as a second argument:

F2 show-text "Quick alert" 1000

3. Combine Actions with Custom Messages

To trigger an actual playback command and display a custom confirmation message simultaneously, chain commands together using a semicolon (;):

ctrl+1 set speed 1.5 ; show-text "Speed: 1.5x Activated"
ctrl+2 set mute yes ; show-text "Audio Muted"

4. Display Dynamic Property Values

You can include dynamic player information inside your custom OSD message by referencing mpv properties inside ${property_name} tags:

F3 show-text "Volume: ${volume}% | Remaining: ${playtime-remaining}"
F4 show-text "Current File: ${filename}"

5. Applying the Changes

Save the input.conf file. If mpv is already running, the changes take effect immediately without requiring a restart. Pressing your designated key or macro will now trigger your custom text overlay directly on the video player.
