Force MPV Subtitles to the Bottom of the Screen

This guide explains how to disable embedded positioning in soft-coded subtitles (such as ASS/SSA tracks) within the MPV media player. By configuring specific override parameters in MPV's configuration file or via the command line, you can strip custom on-screen positioning metadata and force all subtitle lines to render uniformly at the bottom of the video window.

Understanding the Problem

Advanced SubStation Alpha (.ass) and SubStation Alpha (.ssa) subtitles often include coordinate tags (such as \pos, \an, or \move) that place dialogue or signs anywhere across the frame. By default, MPV honors these embedded script instructions. To force them to the bottom, you must instruct MPV's subtitle renderer to override or strip these script styles.

Step 1: Locate or Create mpv.conf

To apply the changes permanently, open your MPV configuration file (mpv.conf) in a text editor. If the file does not exist, create it in the appropriate directory for your operating system:

  • Windows: %APPDATA%\mpv\mpv.conf (or portable_config\mpv.conf if using a portable build)
  • Linux: ~/.config/mpv/mpv.conf
  • macOS: ~/.config/mpv/mpv.conf

Step 2: Add Subtitle Override Settings

Add the following lines to your mpv.conf:

# Strip embedded ASS styles and position tags
sub-ass-override=strip

# Align subtitles to the bottom
sub-align-y=bottom

# Set vertical position (100 represents the bottom margin limit)
sub-pos=100

Override Mode Options:

  • sub-ass-override=strip: Completely removes all ASS formatting tags (including fonts, colors, animations, and coordinates). This is the most reliable way to force all subtitles to the bottom as plain text.
  • sub-ass-override=force: Enforces your user-defined styles (fonts, font size, margins) over the embedded ones, but attempts to retain basic inline formatting (like bold or italics) where possible.

Using Command-Line Parameters

If you want to apply this behavior for a single video session without editing mpv.conf, pass the arguments directly via the terminal or command prompt:

mpv --sub-ass-override=strip --sub-align-y=bottom --sub-pos=100 video.mkv

Optional: Toggle Overrides with a Keybind

To toggle between original positioning and forced bottom positioning during playback, map a key in your input.conf file:

# Press 'k' to toggle ASS style overriding
k cycle_values sub-ass-override "strip" "no"
