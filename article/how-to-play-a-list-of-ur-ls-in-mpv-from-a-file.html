How to Play a List of URLs in mpv from a File

Playing a sequence of online media files in mpv without manually adding each link is simple using built-in playlist functionality. This guide explains how to use the --playlist command-line argument to load a plain text file containing web links and have mpv stream and play them sequentially from start to finish.

The Command Line Argument

The command line option used to pass a text file of URLs to mpv is --playlist.

To run it, use the following syntax in your terminal or command prompt:

mpv --playlist=urls.txt

Replace urls.txt with the relative or absolute path to your file.

Formatting the URL List File

The text file itself should be a simple plain text file (UTF-8 encoded) with each URL placed on its own line:

https://example.com/video1.mp4
https://example.com/stream2.m3u8
https://www.youtube.com/watch?v=dQw4w9WgXcQ

Blank lines and lines starting with # are treated as comments and ignored by mpv.

Useful Additional Arguments

You can combine --playlist with other mpv flags to control playback behavior:

  • Loop the playlist: To continuously repeat the entire list once playback finishes, add --loop-playlist: 
    mpv --playlist=urls.txt --loop-playlist=inf
  • Shuffle playback: To play the links in a random order rather than sequentially: 
    mpv --playlist=urls.txt --shuffle
  • Start from a specific item: To jump straight to an entry (indexes start at 0): 
    mpv --playlist=urls.txt --playlist-start=2

Reading from Standard Input

If you generate a list of URLs dynamically, you can pass standard input to mpv using a hyphen (-):

cat urls.txt | mpv --playlist=-
