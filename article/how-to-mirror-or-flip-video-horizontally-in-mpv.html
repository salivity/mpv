How to Mirror or Flip Video Horizontally in mpv

Flipping or mirroring a video horizontally in mpv is a straightforward process achieved through the player's built-in video filter system. Whether you need to mirror a single video from the command line, toggle the effect dynamically with a keypress during playback, or apply it to every video by default, mpv uses the hflip filter to achieve the desired output.

1. Launch with Horizontal Flip via Command Line

To open and mirror a video immediately from your terminal or command prompt, pass the hflip filter using the --vf (video filter) option:

mpv --vf=hflip "your-video.mp4"

This applies the horizontal mirror effect to the video track for the duration of that session without altering the original file.

2. Toggle the Flip Effect During Playback

To turn the horizontal flip on and off dynamically using a keyboard shortcut, you can add a custom binding to your input.conf file.

  1. Locate or create your input.conf file in the mpv configuration directory:
    • Linux/macOS: ~/.config/mpv/input.conf
    • Windows: %APPDATA%/mpv/input.conf or inside the portable_config directory where mpv.exe resides.
  2. Add the following line:
Ctrl+h vf toggle hflip

Save the file. When playing a video, pressing Ctrl + h will instantly switch between normal and mirrored orientation.

3. Toggle via the In-Player Console

If you do not have keybindings set up, you can enable the filter during playback using mpv's interactive console:

  1. Press the grave accent / tilde key (` or ~) while a video is playing to open the console.
  2. Type the following command and press Enter:
vf toggle hflip

Repeat the command to disable the effect.

4. Set Horizontal Flip as Default

To ensure every video opened in mpv starts with a horizontal flip, add the filter to your mpv.conf file:

  1. Open your mpv.conf file located in the mpv configuration directory.
  2. Add the following entry:
vf=hflip

Save the file. All future playback sessions will launch with the horizontal flip effect pre-applied.
