How to Set Fallback Video Output Drivers in mpv

Configuring fallback video output drivers in the mpv media player ensures uninterrupted playback across diverse hardware platforms and display servers. This guide explains the correct syntax for chaining multiple video output (VO) drivers using both command-line arguments and configuration files, enabling mpv to automatically fall back to secondary drivers if your primary choice fails to initialize.

The Fallback Syntax

In mpv, the video output driver is configured using the --vo option. To specify multiple fallback drivers, pass them as a comma-separated list without spaces. mpv attempts to load the drivers in order from left to right. If the first driver encounters an initialization error or is unavailable on the current system, mpv moves to the next driver in the list.

Setting Fallback Drivers via Command Line

To launch a video with a fallback chain directly from the terminal, supply the comma-separated list to the --vo flag:

mpv --vo=gpu-next,gpu,x11 video.mkv

In this example, mpv first attempts to use gpu-next (the modern libplacebo-based renderer). If your hardware, operating system, or drivers do not support it, mpv drops back to standard gpu. If GPU acceleration fails entirely, it defaults to the x11 software driver.

Setting Fallback Drivers in mpv.conf

To apply fallback drivers permanently, add the vo directive to your mpv.conf configuration file:

vo=gpu-next,gpu,xv,x11

Depending on your operating system, the mpv.conf file is typically located at:

  • Linux/macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%\mpv\mpv.conf or in the portable_config folder adjacent to mpv.exe.

Passing Sub-Options to Drivers in a Fallback Chain

If specific drivers require individual configurations, append driver-specific sub-options to that particular entry using colons:

vo=gpu:api=vulkan,gpu:api=opengl,x11

Here, mpv attempts to initialize the gpu output driver with the Vulkan backend first. If Vulkan fails, it attempts to initialize the gpu driver with OpenGL before falling back to x11.

Verifying Available Video Drivers

Before building a fallback list, determine which drivers your specific mpv build supports by running:

mpv --vo=help

This command outputs a list of compiled-in drivers on your system, helping prevent invalid entries in your fallback chain.
