What Does sub-auto=fuzzy Do in mpv?

The sub-auto=fuzzy option in the mpv media player allows the player to automatically detect and load external subtitle files that contain the media file's name, rather than requiring an exact match. This article explains the exact behavior of fuzzy subtitle loading in mpv, compares it with alternative sub-auto settings, and demonstrates how to apply it in your configuration.

How sub-auto=fuzzy Works

By default, media players often look for subtitle files that share the exact filename of the video being played. When you set --sub-auto=fuzzy in mpv, the matching rules are relaxed. mpv scans the directory containing the video file (as well as any directories specified in sub-file-paths) and loads any subtitle file whose name contains the video file's base name.

For example, if you open a video named: FeatureFilm.2024.1080p.mkv

A strict matching rule would only load: FeatureFilm.2024.1080p.srt

With sub-auto=fuzzy enabled, mpv will automatically recognize and load files such as:

  • FeatureFilm.2024.1080p.en.srt
  • FeatureFilm.2024.1080p.es.sub
  • FeatureFilm.2024.1080p.forced.ass

This makes fuzzy particularly useful for multi-language releases or files labeled with additional metadata like language codes, subtitle formats, or hearing-impaired tags.

Comparison with Other sub-auto Modes

mpv provides four primary modes for the sub-auto setting:

  • no: Disables automatic loading entirely. No external subtitles are loaded unless manually specified.
  • exact: The default behavior. Only loads subtitle files that match the media filename character-for-character before the file extension.
  • fuzzy: Loads all subtitle files containing the media filename.
  • all: Automatically loads every subtitle file found in the current directory and configured subtitle paths, regardless of whether the names match the video.

How to Configure sub-auto=fuzzy

You can enable fuzzy matching on the fly via the command line:

mpv --sub-auto=fuzzy "FeatureFilm.2024.1080p.mkv"

To make this behavior permanent for all media playback, add the setting directly to your mpv.conf configuration file:

sub-auto=fuzzy
