How to Enable 3D Stereoscopic Playback in mpv

This guide explains how to configure and use the mpv media player to properly display stereoscopic 3D videos, including Side-by-Side (SBS) and Top-and-Bottom (TAB/Over-Under) formats. By leveraging mpv's underlying FFmpeg video filters, you can easily convert 3D formats into standard 2D (monoscopic), red-cyan anaglyph, or alternative stereoscopic layouts in real time using command-line flags, configuration files, or custom keyboard shortcuts.

Using the stereo3d Filter via Command Line

mpv processes stereoscopic content through FFmpeg's stereo3d video filter. The syntax follows the format --vf=stereo3d=in:out, where in is the input format of the video file and out is your desired display output.

Common Input Codes

  • sbsl: Side-by-side, left eye first (Full SBS)
  • sbs2l: Side-by-side half width, left eye first (Half-SBS)
  • abl: Above-below (top-and-bottom), left eye first (Full TAB)
  • ab2l: Above-below half height, left eye first (Half-TAB)

Common Output Codes

  • ml: Mono left eye (converts 3D video to standard 2D using only the left eye)
  • mr: Mono right eye (converts 3D video to standard 2D using only the right eye)
  • arrc: Red/cyan anaglyph (color-optimized)
  • arbg: Red/blue anaglyph
  • al: Alternating frames (for active shutter glasses)

Example Commands

1. Watch Half-SBS as Standard 2D

To display only one eye and watch a Half-SBS video on a normal 2D display:

mpv --vf=stereo3d=sbs2l:ml "video.mp4"

2. Watch Half-SBS with Red/Cyan Glasses

To convert Half-SBS video into classic red/cyan anaglyph 3D:

mpv --vf=stereo3d=sbs2l:arrc "video.mp4"

3. Watch Top-and-Bottom (Half-TAB) as Standard 2D

mpv --vf=stereo3d=ab2l:ml "video.mp4"

4. Watch Top-and-Bottom (Half-TAB) with Red/Cyan Glasses

mpv --vf=stereo3d=ab2l:arrc "video.mp4"

Adding Shortcuts to input.conf

Instead of typing parameters in the terminal each time, you can bind keys to toggle these filters while a video is playing. Open or create your input.conf file (located in ~/.config/mpv/ on Linux/macOS or %APPDATA%/mpv/ on Windows) and add the following lines:

# Toggle Half-SBS to 2D
Ctrl+1 vf toggle stereo3d=sbs2l:ml

# Toggle Half-SBS to Red/Cyan Anaglyph
Ctrl+2 vf toggle stereo3d=sbs2l:arrc

# Toggle Half-TAB to 2D
Ctrl+3 vf toggle stereo3d=ab2l:ml

# Toggle Half-TAB to Red/Cyan Anaglyph
Ctrl+4 vf toggle stereo3d=ab2l:arrc

# Clear all video filters
Ctrl+0 vf set ""

Pressing the mapped key combinations during playback will immediately switch the video between stereoscopic modes and standard rendering.
