How to Show Embedded Album Art in mpv

By default, the mpv media player plays audio files without opening a video window, keeping embedded cover images hidden. This guide details how to configure mpv to automatically display embedded album art from MP3, FLAC, and other audio containers, both through command-line parameters and by saving the setting permanently inside your configuration file.

Understanding mpv Audio Display Settings

The behavior of album art rendering in mpv is controlled by the --audio-display option. It supports three distinct modes:

  • attachment: Displays embedded album art images (such as ID3 APIC frames in MP3s or Vorbis comments in FLACs).
  • no: Completely disables the video window during audio playback.
  • yes: The default behavior, which enables video display if video streams are detected, but may not prioritize audio-embedded static images depending on your platform and build.

To force mpv to always parse and show embedded cover art, set this option to attachment.

Method 1: Using the Command Line

To test the behavior without altering your permanent settings, pass the --audio-display=attachment flag when launching mpv:

mpv --audio-display=attachment song.mp3

For FLAC files containing embedded metadata:

mpv --audio-display=attachment album.flac

If the window does not appear immediately when audio starts, you can add --force-window=yes to ensure the player creates a visual window right away:

mpv --audio-display=attachment --force-window=yes song.mp3

Method 2: Making the Configuration Permanent

To avoid typing the flag every time you play an audio file, add the directive to your mpv.conf file.

1. Locate or Create mpv.conf

  • Linux / BSD: ~/.config/mpv/mpv.conf
  • macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config directory if using a portable build)

2. Add the Configuration Directives

Open mpv.conf in any plain text editor and add the following lines:

# Force the display of embedded album art
audio-display=attachment

# Ensure the display window opens immediately upon playback
force-window=yes

Save the file and restart mpv. Whenever an MP3 or FLAC file with embedded cover art is played, mpv will now open a dedicated window showing the image.

Optional: Handling External Cover Art Files

If some of your music folders use external images (such as cover.jpg, folder.png, or album.jpg) instead of embedded metadata, you can instruct mpv to automatically load them alongside your audio files.

Add the following to your mpv.conf:

# Automatically search for external cover art matching common filenames
cover-art-auto=fuzzy

Setting cover-art-auto to fuzzy allows mpv to load images in the same directory whose names partially match the track or use common naming conventions like cover, front, or folder. If set to exact, mpv only loads image files that match the exact filename of the audio track.
