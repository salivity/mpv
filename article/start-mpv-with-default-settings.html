Start MPV With Default Settings

When troubleshooting playback issues or testing a clean setup in the mpv media player, it is often necessary to bypass custom scripts, keybindings, and configurations. This guide explains how to launch mpv in its pure, default state by using a single command line argument that forces the application to ignore all user-level and system-wide configuration files.

The command line flag used to ignore all configuration files in mpv is --no-config.

When you pass --no-config to the executable, mpv completely skips loading configuration files such as mpv.conf and input.conf, as well as any Lua or JavaScript user scripts located in your configuration directories (such as ~/.config/mpv/ on Linux/macOS or %APPDATA%/mpv/ on Windows).

Basic Syntax

To play a file using the default settings, run the following command in your terminal or command prompt:

mpv --no-config video.mp4

Why Use --no-config

Using --no-config is primarily helpful for:

  • Troubleshooting: Identifying whether a playback issue, crash, or unexpected behavior is caused by a custom shader, script, or video output driver setting.
  • Bug Reporting: Mpv developers typically require bug reports to be verified using --no-config to ensure the issue is present in the core player and not introduced by third-party additions.
  • Isolated Testing: Testing command-line options individually without interference from persistent settings defined in your mpv.conf.

You can still combine --no-config with other command-line flags. Any options explicitly passed alongside --no-config in the terminal will apply, allowing you to test specific settings in complete isolation.
