Run mpv Scripts for Audio-Only Files

You can configure mpv to execute specific scripts or actions exclusively when playing audio-only files by using a conditional Lua script. While mpv automatically loads all scripts found in its scripts folder at startup, a script can detect whether the current media lacks a video stream and conditionally run your desired logic.

How mpv Handles Audio-Only Detection

Because mpv does not support conditionally loading script files via mpv.conf, the recommended solution is to wrap your custom functionality inside a condition that listens for the file-loaded event. This allows the script to inspect the active tracks and only execute when no video track is present.

Step-by-Step Implementation

  1. Open your mpv configuration directory:

    • Linux/macOS: ~/.config/mpv/scripts/
    • Windows: %APPDATA%/mpv/scripts/

  2. Create a new file, for example, audio-only-action.lua.

  3. Insert the following code template:

local function run_audio_script()
    -- Get the video track status
    local vid = mp.get_property_native("vid")
    local video_format = mp.get_property("video-format")

    -- Check if there is no video track or if video format is nil
    if not vid or vid == false or not video_format then
        -- Insert the specific actions you want to run here
        mp.msg.info("Audio-only file detected. Running custom script logic.")

        -- Example: Display a persistent OSD message or run an external command
        mp.osd_message("Playing audio-only file", 3)
    end
end

-- Hook into the event that fires whenever a new media file finishes loading
mp.register_event("file-loaded", run_audio_script)

Handling Embedded Cover Art

Many audio files (such as MP3 or FLAC files) contain embedded album art, which mpv treats as a video track by default. If you want the script to treat files with static cover art as audio-only files, check if the video stream is an image format or attached picture:

local function is_audio_only()
    local vid = mp.get_property_native("vid")
    if not vid or vid == false then
        return true
    end

    -- Check if the track is just an attached picture
    local track_list = mp.get_property_native("track-list", {})
    for _, track in ipairs(track_list) do
        if track.type == "video" and track.selected then
            if track.albumart then
                return true
            end
        end
    end

    return false
end

mp.register_event("file-loaded", function()
    if is_audio_only() then
        -- Your custom audio-only commands go here
    end
end)

Triggering Existing Scripts Using Profiles

If you want an existing third-party script to change its behavior during audio playback, you can use conditional profiles in your mpv.conf to toggle script-opts:

[audio-profile]
profile-cond=vid == false or get("current-tracks/video/albumart", false) == true
script-opts=yourscript-enabled=yes

This ensures that the script options update dynamically whenever an audio-only file is loaded into the player.
