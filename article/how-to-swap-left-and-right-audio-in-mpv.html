How to Swap Left and Right Audio in mpv

mpv allows users to swap the left and right stereo audio channels directly during playback without restarting the media player. By using mpv's built-in audio filter engine with the pan filter, you can dynamically reverse stereo channels using the in-player console, a custom keyboard shortcut, or command-line flags.

Swapping Channels Using the mpv Console

You can swap audio channels during playback via mpv’s interactive console:

  1. Press the backtick key (`) or ~ while a video or audio file is playing to open the on-screen console.
  2. Type the following command and press Enter: 
    af toggle "pan=stereo|c0=c1|c1=c0"
  3. Pressing Enter applies the filter immediately. Entering the same command again toggles the filter off, returning the audio to normal.

Setting Up a Keyboard Shortcut

To switch channels frequently, bind the command to a key in your input.conf file:

  1. Locate or create input.conf in your mpv configuration directory:
    • Linux/macOS: ~/.config/mpv/input.conf
    • Windows: %APPDATA%/mpv/input.conf (or inside the portable_config folder)
  2. Add a keybinding line, for example using Ctrl+x: 
    Ctrl+x af toggle "pan=stereo|c0=c1|c1=c0"
  3. Save the file. Pressing Ctrl+x will now toggle the left and right channels during playback.

How the Filter Works

The filter string pan=stereo|c0=c1|c1=c0 works by remapping the audio channels:

  • stereo: Sets the output layout to standard 2-channel stereo.
  • c0=c1: Maps output channel 0 (Left) to input channel 1 (Right).
  • c1=c0: Maps output channel 1 (Right) to input channel 0 (Left).
  • af toggle: Adds the filter if absent, or removes it if already active.

Launching mpv with Swapped Channels

If you want to start mpv with swapped channels from the terminal, pass the filter as a startup argument:

mpv --af="pan=stereo|c0=c1|c1=c0" "filename.mkv"
