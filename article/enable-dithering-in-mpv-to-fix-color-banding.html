Enable Dithering in mpv to Fix Color Banding

Color banding occurs on 8-bit displays when color gradients lack enough bit depth to transition smoothly, producing harsh, visible lines across skies, shadows, and flat surfaces. Dithering resolves this by scattering pixels of neighboring colors along the gradient boundaries, simulating higher bit depth and smoother transitions to the human eye. This guide outlines how to configure mpv's built-in dithering engine directly through its configuration file to eliminate banding on 8-bit screens.

1. Locate or Create the mpv Configuration File

To apply permanent settings, edit your mpv.conf file. If the file does not exist, create it as a plain text file named mpv.conf in the following directory according to your operating system:

  • Windows: %APPDATA%\mpv\mpv.conf (e.g., C:\Users\<Username>\AppData\Roaming\mpv\mpv.conf)
  • Linux: ~/.config/mpv/mpv.conf
  • macOS: ~/.config/mpv/mpv.conf

2. Configure Dithering Settings

Open mpv.conf in a text editor and append the following lines:

# Force dithering bit depth to match an 8-bit display
dither-depth=8

# Select the dithering algorithm
dither=fruit

# Increase the matrix size for fruit dithering (reduces repeating patterns)
dither-size-fruit=8

Explanation of Options:

  • dither-depth=8: Instructs mpv to dither down to 8 bits per channel. While auto attempts to query the operating system, explicitly setting it to 8 prevents color banding caused by incorrect OS display bit-depth reporting.
  • dither=fruit: Uses the "Fruit" dithering algorithm, which offers an optimal balance between visual quality and GPU performance. If your GPU supports compute shaders and you prioritize maximum quality, you can use dither=error-diffusion instead.
  • dither-size-fruit=8: Expands the spatial matrix of the Fruit algorithm to 8x8 (default is 6), which suppresses visible dithering patterns in large gradients.

3. Enable the Debanding Filter (Recommended)

Dithering only smooths out banding introduced by outputting high-precision video onto an 8-bit panel; it cannot remove banding already encoded into the source file. To address source banding alongside dithering, enable mpv’s debanding engine by adding:

# Enable source debanding
deband=yes

# Deband filter parameters
deband-iterations=4
deband-threshold=48
deband-range=16
deband-grain=48
  • deband-iterations: Controls the number of debanding passes. Higher values smooth more aggressive banding at the expense of GPU performance.
  • deband-threshold: The deband filter sensitivity. Higher values remove more banding but may soften fine details.
  • deband-range: The radius around each pixel checked for banding.
  • deband-grain: Adds artificial dynamic grain to masked gradients to mask remaining artifacts and prevent new banding from forming.

4. Verify in Playback

Save the mpv.conf file and launch any video in mpv. During playback, press Shift + I to open the statistics overlay, then press 2 to view frame timings and rendering details. Ensure the display bit depth is actively recognized and that the deband/dither pipeline is active.
