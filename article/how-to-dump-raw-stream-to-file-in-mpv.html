How to Dump Raw Stream to File in MPV

This guide explains how to capture and save raw audio or video streams directly to a local file using the mpv media player. By using built-in command-line flags, you can dump live network streams or media file data without re-encoding, preserving the original quality while avoiding unnecessary CPU usage.

Recording the Raw Input Stream

The standard method to dump an active network or media stream directly to disk is using the --stream-record option. This writes the raw stream data received from the source directly into the specified file:

mpv "https://example.com/stream.m3u8" --stream-record="output.ts"

While the stream plays, mpv writes the packets directly to output.ts. You can stop the capture at any time by quitting mpv (pressing q).

Note: On older versions of mpv, the deprecated alias --record-file was used for this function.

Dumping Streams Without Playback (Encoding Mode)

If you have a local file or stream and want to extract the raw video or audio tracks into a container without displaying the video window, use mpv's stream-copy mode.

1. Dump Both Audio and Video (Copy Mode)

mpv "input.mkv" --o="output.mp4" --ovc=copy --oac=copy

2. Dump Only Raw Audio

To extract the audio stream without re-encoding:

mpv "input.mkv" --o="output.aac" --ovc=null --oac=copy

3. Dump Only Raw Video

To extract the video stream without re-encoding:

mpv "input.mkv" --o="video_only.mp4" --ovc=copy --oac=null

Using --ovc=copy and --oac=copy bypasses decoding and re-encoding, ensuring a rapid bitstream dump to the destination container.
