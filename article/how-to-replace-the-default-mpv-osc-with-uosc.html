How to Replace the Default mpv OSC with uosc

This guide provides a straightforward, step-by-step walkthrough for replacing the standard on-screen controller (OSC) in mpv with uosc. By following these instructions, you will learn how to locate your mpv configuration directory, disable the built-in controller to prevent visual conflicts, and properly install the uosc script along with its required components for a modern, minimalist media player interface.

Step 1: Locate Your mpv Configuration Directory

Before installing the script, navigate to your mpv configuration folder. If the folder does not exist, create it manually:

  • Windows: %APPDATA%\mpv\ (or the folder containing mpv.exe if running in portable mode)
  • Linux: ~/.config/mpv/
  • macOS: ~/.config/mpv/

Step 2: Disable the Built-in OSC

uosc provides its own UI, so you must disable mpv's default controller to avoid overlapping interfaces.

  1. Open (or create) the mpv.conf file inside your mpv configuration folder.
  2. Add the following lines:
osc=no
osd-bar=no
border=no

Setting border=no is optional, but it enables uosc to render custom, sleek window controls.

Step 3: Download and Extract uosc

  1. Visit the official uosc releases page on GitHub and download the latest uosc.zip package.
  2. Extract the contents directly into your mpv configuration directory.

Ensure the extracted files match this directory structure:

mpv/
├── mpv.conf
├── fonts/
│   └── uosc_icons.otf
└── scripts/
    └── uosc/

Note: Depending on the release version, uosc may include a font file in a fonts folder. This font is required to display UI icons properly.

Step 4: Verify the Installation

Launch any video file using mpv. Move your cursor over the player window. The native controller will be gone, replaced by the modern, context-aware uosc interface that displays sleek seekbars, chapter markers, and timeline previews.
