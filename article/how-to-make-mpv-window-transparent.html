How to Make MPV Window Transparent

You can make the mpv media player window transparent so that only the video content is visible. By disabling window borders, turning off the on-screen controller, and configuring background alpha values, mpv can eliminate all user interface elements and render black bars or alpha-channel video transparently against your desktop.

1. Remove Window Borders and UI Elements

To ensure no window chrome or default controls appear around your video, launch mpv with options that disable the title bar and default interface:

  • --no-border: Disables the operating system window frame and title bar.
  • --no-osc: Disables the default on-screen controller bar that appears when moving the mouse.
  • --no-osd-bar: Disables the seek and volume progress bar overlays.

2. Enable Transparency for Letterboxing and Backgrounds

By default, mpv fills empty space around non-matching aspect ratios with black bars. You can force the player background to be fully transparent using the background color setting:

--background-color='#00000000'

The eight-digit hex code represents #RRGGBBAA. Setting the alpha component (AA) to 00 makes all unused window space 100% transparent, provided your operating system has desktop composition enabled (such as Desktop Window Manager on Windows or a compositor like Picom/Wayland on Linux).

3. Handle Transparent Video Formats (Alpha Channels)

If your video file natively contains an alpha channel (such as a WebM with VP8/VP9 transparency or ProRes 4444), you must tell mpv how to handle the alpha layer:

--alpha=blend

This ensures the video's transparent regions display the desktop underneath rather than a solid black fill.

4. Complete Configuration File (mpv.conf)

To apply these settings permanently without entering them in the terminal each time, add the following lines to your mpv.conf file:

# Remove window borders and UI
no-border
no-osc
no-osd-bar

# Enable transparency
alpha=blend
background-color='#00000000'

# Keep window on top (optional, useful for floating transparent video)
ontop=yes

Once saved, any video launched with mpv will display strictly the video frame floating seamlessly over your other desktop applications.
