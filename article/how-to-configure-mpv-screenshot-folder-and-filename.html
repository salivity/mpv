How to Configure MPV Screenshot Folder and Filename

This guide explains how to customize the screenshot directory and file naming format in the mpv media player. By modifying the mpv.conf configuration file, you can dictate exactly where screenshots are stored, define custom file naming conventions using dynamic variables, and select the output image format.

Step 1: Locate or Create mpv.conf

To apply persistent settings, you must add your options to the mpv.conf configuration file. If the file does not exist, create it in the appropriate directory for your operating system:

  • Linux and macOS: ~/.config/mpv/mpv.conf
  • Windows (Standard): C:\Users\<Username>\AppData\Roaming\mpv\mpv.conf
  • Windows (Portable): Place mpv.conf inside the portable_config folder in the same directory as mpv.exe.

Step 2: Set the Screenshot Directory

Use the screenshot-directory property to define the target folder. You can use absolute paths or relative paths.

Linux / macOS:

screenshot-directory="~/Pictures/mpv_screenshots"

Windows:

screenshot-directory="C:\Users\YourUsername\Pictures\mpv_screenshots"

Note: Make sure the designated folder exists, as mpv will not automatically create the directory on some platforms.

Step 3: Define the File Naming Template

Use the screenshot-template option to format the file names. mpv uses format specifiers that automatically populate details like media title, playback time, and sequence numbers.

Common format specifiers include:

  • %F: The filename of the currently playing media without the file extension.
  • %f: The full filename of the currently playing media including the extension.
  • %p: Current playback time in HH:MM:SS format.
  • %P: Current playback time in milliseconds.
  • %n: A sequential number padded to four digits (e.g., 0001, 0002).
  • %tY, %tm, %td: Current year, month, and day.
  • %tH, %tM, %tS: Current system hour, minute, and second.

Example template:

screenshot-template="%F_%p_%n"

If playing a file named movie.mkv at the 12-minute and 34-second mark, this generates a filename like movie_00:12:34_0001.png.

To prevent invalid filename characters on Windows caused by colons in %p, you can format the time using %wH.%wM.%wS or replace %p with %P (playback time in total seconds):

screenshot-template="%F_%wH.%wM.%wS_%n"

Step 4: Optional Configuration Options

You can further refine your screenshots by setting the format and quality level in the same file:

# Choose image format: png, jpg, webp (default is png)
screenshot-format=png

# Compression for PNG (0-9, 7 is default)
screenshot-png-compression=7

# Quality for JPEG (0-100, 90 is default)
screenshot-jpeg-quality=95

# Include subtitles in screenshots (yes/no)
screenshot-tag-colorspace=yes

Complete Example Configuration

Add the following block to your mpv.conf file:

# Output folder
screenshot-directory="~/Pictures/Screenshots"

# File name structure: [VideoName]_[Timestamp]_[Counter]
screenshot-template="%F_%wH.%wM.%wS_%n"

# Output format
screenshot-format=png
screenshot-png-compression=7

Save the file and restart mpv. Pressing s will now take a screenshot with subtitles, while Shift+s will capture the frame without subtitles, saving both to your specified folder using your custom naming pattern.
