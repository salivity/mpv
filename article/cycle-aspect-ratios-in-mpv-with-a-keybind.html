Cycle Aspect Ratios in mpv With a Keybind

This guide explains how to configure the mpv media player to cycle through custom aspect ratios—specifically 16:9, 4:3, and 21:9—using a single keyboard shortcut. By adding a single line to mpv's key-binding configuration file, you can easily toggle video dimensions on the fly without navigating complex menus.

1. Locate or Create the input.conf File

mpv handles custom keybindings through a configuration file named input.conf. Depending on your operating system, this file is located in the following directory:

  • Linux / macOS: ~/.config/mpv/input.conf
  • Windows (standard install): %APPDATA%\mpv\input.conf (typically C:\Users\<Username>\AppData\Roaming\mpv\input.conf)
  • Windows (portable install): In the portable_config directory inside the folder where mpv.exe is located.

If the mpv folder or the input.conf file does not exist, create them manually using any standard plain text editor.

2. Add the Aspect Ratio Cycle Command

Open input.conf in a text editor and add the following line:

A cycle-values video-aspect-override "16:9" "4:3" "21:9" "-1"

3. How the Command Works

  • A: The keyboard key assigned to the action. In this example, it is bound to Shift + a (capital A). You can replace this with any available key, such as Ctrl+a or F8.
  • cycle-values: The mpv command that iterates sequentially through a list of values each time the assigned key is pressed.
  • video-aspect-override: The internal property that forces a specific aspect ratio onto the playing video.
  • "16:9" "4:3" "21:9": The custom ratios that the player will cycle through.
  • "-1": Resets the aspect ratio back to the video's original/native ratio. This ensures you can return to the default setting without restarting playback.

4. Save and Test

Save the input.conf file and restart mpv (or load a new video). Press your mapped key while the video is playing to verify that it smoothly cycles through 16:9, 4:3, 21:9, and back to original.
