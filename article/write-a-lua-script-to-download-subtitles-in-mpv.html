Write a Lua Script to Download Subtitles in MPV

MPV is an extensible, minimalist media player that allows users to automate playback features using Lua scripting. This article demonstrates how to build a custom Lua script that captures the path of the currently playing video, calls an external subtitle-fetching tool through an asynchronous subprocess, and automatically loads the newly downloaded subtitle track without restarting playback.

Prerequisites

To download subtitles reliably, your Lua script should delegate network requests and subtitle provider APIs to an established command-line utility. A common, effective tool for this is Subliminal, a Python-based CLI that searches multiple subtitle providers. Ensure it is installed on your system:

pip install subliminal

Ensure subliminal is available in your system's PATH.

1. Locate the MPV Scripts Directory

MPV looks for user-defined scripts inside a dedicated directory. If this folder does not exist, create it:

  • Linux/macOS: ~/.config/mpv/scripts/
  • Windows: %APPDATA%/mpv/scripts/

Create a new file named fetch_subtitles.lua inside this directory.

2. The Lua Script Implementation

Paste the following code into fetch_subtitles.lua:

local mp = require 'mp'
local utils = require 'mp.utils'

local function on_subtitles_fetched(success, result, error)
    if result and result.status == 0 then
        mp.osd_message("Subtitles downloaded successfully!", 3)
        -- Reload external subtitle files and auto-select the best match
        mp.commandv("rescan-external-files", "reselect")
    else
        mp.osd_message("Subtitle download failed.", 4)
    end
end

local function fetch_subtitles()
    -- Retrieve the file path of the current video
    local video_path = mp.get_property("path")

    -- Check if the current media is a local file
    if not video_path or video_path:find("^https?://") then
        mp.osd_message("Cannot fetch subtitles for non-local media", 3)
        return
    end

    mp.osd_message("Fetching subtitles...", 10)

    -- Define the command and arguments (subliminal downloading English subs)
    local command = {
        name = "subprocess",
        playback_only = false,
        capture_stdout = true,
        capture_stderr = true,
        args = {
            "subliminal",
            "download",
            "-l", "en",
            video_path
        }
    }

    -- Execute asynchronously to avoid freezing the player interface
    mp.command_native_async(command, on_subtitles_fetched)
end

-- Expose the function to MPV keybindings
mp.add_key_binding("Ctrl+S", "download_subs", fetch_subtitles)

3. How the Script Works

  • mp.get_property("path"): Retrieves the path of the actively loaded video file.
  • Safety Check: Validates that a file is currently playing and ignores web streams (like YouTube links) where local subtitle fetching would fail.
  • mp.command_native_async: Runs the CLI tool in the background. Running it asynchronously ensures that video playback and the user interface do not freeze while the network request is processing.
  • mp.commandv("rescan-external-files", "reselect"): Signals MPV to refresh the directory for new subtitle tracks and select the newly added track once the CLI command exits with status 0.
  • mp.add_key_binding: Assigns the trigger to a keyboard shortcut (Ctrl+S).

4. Customizing Keybindings

Instead of hardcoding the shortcut within the Lua script, you can expose it as a script binding by replacing the mp.add_key_binding line with:

mp.register_script_binding(fetch_subtitles, "download_subs")

Then, assign any custom key inside your input.conf file:

b script-binding download_subs
