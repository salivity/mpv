mpv VAAPI Hardware Decoding on Linux: Intel and AMD

The mpv media player natively supports VAAPI (Video Acceleration API) hardware decoding on Linux for both Intel and AMD graphics processors. Utilizing VAAPI offloads video decoding from the CPU to dedicated hardware on your GPU, resulting in significantly lower CPU usage, cooler operating temperatures, and extended battery life on laptops. This article details the prerequisites, configuration options, and verification steps necessary to enable and use VAAPI with mpv on Linux.

Driver Prerequisites

Before enabling VAAPI in mpv, your Linux system requires the appropriate user-space drivers:

  • Intel Graphics: Older Intel GPUs (Broadwell and earlier) use intel-vaapi-driver (i965). Modern Intel GPUs (Skylake and newer, including Arc discrete graphics) require intel-media-driver (iHD).
  • AMD Graphics: AMD GPUs use the open-source Mesa drivers. Hardware acceleration is provided by the mesa-va-drivers package (often named libva-mesa-driver depending on your Linux distribution).

You can confirm that your system recognizes the VAAPI driver by running the following command in your terminal:

vainfo

If configured correctly, the output will display your driver name and a list of supported video codecs (such as H.264, HEVC, VP9, and AV1) along with VAEntrypointVLD (indicating decoding capability).

Configuring mpv to Use VAAPI

To enable VAAPI hardware decoding on a single playback session, run mpv from the terminal with the --hwdec flag:

mpv --hwdec=vaapi video.mp4

To make this setting permanent across all media files, add the configuration directly to your mpv configuration file, typically located at ~/.config/mpv/mpv.conf:

vo=gpu
hwdec=vaapi

Alternatively, setting hwdec=auto-safe allows mpv to automatically detect and enable VAAPI when supported, while safely falling back to software decoding if a specific format or profile is not supported by your hardware.

Direct vs. Copy-Back Modes

  • hwdec=vaapi (Direct): The decoded video frames remain in GPU memory and are displayed directly. This mode provides the highest performance and the lowest power consumption.
  • hwdec=vaapi-copy (Copy-back): The decoded frames are copied back from GPU memory into system RAM. This allows the use of mpv's advanced software video filters or custom shaders, but introduces a slight performance overhead.

Verifying Hardware Decoding During Playback

To verify that mpv is actively using VAAPI during playback:

  1. Play any supported video file using mpv.
  2. Press Shift + I to display the on-screen playback statistics.
  3. Look for the Hardware decoding field. If active, it will state vaapi (or vaapi-copy) alongside the current video format. If it displays no, mpv has fallen back to CPU software decoding.
