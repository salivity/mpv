Using mpv EDL to Automatically Skip Video Parts

The mpv media player natively supports Edit Decision Lists (EDL) to automatically skip unwanted segments of a video, such as commercials, intros, or specific scenes, without needing to re-encode the file. Instead of defining what to cut, mpv’s EDL implementation works by defining the exact segments you want to play, seamlessly jumping over any timecodes left out of the list.

How mpv Handles EDL Files

mpv uses its own straightforward format known as mpv EDL v0. Rather than traditional editing EDL formats (like CMX 3600), mpv requires a plain text file listing the target source file, the start time of the segment, and the duration of the segment.

Whenever playback reaches the end of a specified segment, it immediately seeks to the start of the next segment.

EDL File Syntax

To create an EDL file:

  1. Create a plain text file and save it with a .edl extension (for example, playlist.edl).
  2. Add the header # mpv EDL v0 on the very first line.
  3. Add entries using comma-separated values in the format: filename,start_time,duration.

Times can be written as seconds with decimal points (e.g., 85.5) or in standard hh:mm:ss.ms notation.

Example

If you have a video named movie.mp4 and you want to play the first two minutes, skip a 30-second commercial, and then play the next five minutes:

# mpv EDL v0
movie.mp4,00:00:00,120
movie.mp4,00:02:30,300

To run the edit, simply pass the EDL file to mpv in your terminal:

mpv playlist.edl

Inline EDL Protocol

You can also bypass creating a text file entirely by using the edl:// pseudo-protocol directly in your command line. Each segment is separated by a semicolon.

For example:

mpv "edl://movie.mp4,0,120;movie.mp4,150,300"

Note: Depending on your terminal shell (like Bash or Zsh), make sure to quote the EDL string so semicolons are not interpreted as shell command separators.

Additional Parameters and Modifiers

The mpv EDL v0 format allows you to specify parameters to customize behavior:

  • Header Parameters: You can set global options such as !global_tags or define fallback file paths.
  • Per-segment Modifiers: You can mute audio during specific segments or choose specific audio/subtitle tracks by setting flags per entry.

By leveraging these native features, mpv can effectively automate non-destructive video playback and scene skipping on the fly.
