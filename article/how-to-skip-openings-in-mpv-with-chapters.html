How to Skip Openings in MPV with Chapters

Configuring mpv to automatically skip opening credits requires using a custom Lua script, as mpv does not include a native setting for title-based chapter skipping. By creating a lightweight script that monitors chapter titles as a video plays, mpv can instantly detect segments labeled as openings, intros, or titles and jump past them automatically.

Step 1: Locate the mpv Scripts Directory

Navigate to your mpv configuration directory and look for a folder named scripts. If the folder does not exist, create it.

  • Linux and macOS: ~/.config/mpv/scripts/
  • Windows (installed): C:\Users\YourUsername\AppData\Roaming\mpv\scripts\
  • Windows (portable): <path_to_mpv>\portable_config\scripts\

Step 2: Create the Lua Skip Script

Inside the scripts directory, create a new file named skip-opening.lua and open it in a plain text editor. Paste the following code into the file:

local mp = require 'mp'

-- Define keywords to search for in chapter titles (case-insensitive)
local skip_titles = {
    "op",
    "opening",
    "intro",
    "opening credits",
    "theme song"
}

local function check_chapter(name, current_chapter)
    if not current_chapter then return end

    local title = mp.get_property_native(string.format("chapter-list/%d/title", current_chapter))
    if not title then return end

    title = string.lower(title)

    for _, skip in ipairs(skip_titles) do
        -- Match exact word or pattern inside the chapter title
        if string.find(title, "%f[%a]" .. skip .. "%f[%A]") or string.find(title, "^" .. skip .. "$") then
            local next_chapter = current_chapter + 1
            local total_chapters = mp.get_property_number("chapters", 0)

            if next_chapter < total_chapters then
                mp.osd_message("Skipping: " .. title, 2)
                mp.set_property_number("chapter", next_chapter)
            end
            break
        end
    end
end

mp.observe_property("chapter", "number", check_chapter)

Save and close the file.

Step 3: Verify and Customize

  1. Test the script: Open any video file in mpv that contains embedded chapter markers labeled "Opening", "Intro", or "OP". When playback hits that chapter, mpv will display an on-screen message and jump directly to the next chapter.
  2. Add custom keywords: If your media files use different names for opening sequences, open skip-opening.lua and add the terms to the skip_titles list in lowercase (e.g., "credit", "precap").

No command-line arguments or changes to mpv.conf are required; mpv automatically loads all .lua scripts found in the scripts directory upon launch.
