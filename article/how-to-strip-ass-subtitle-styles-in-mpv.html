How to Strip ASS Subtitle Styles in MPV

Advanced SubStation Alpha (ASS) subtitles often include hardcoded fonts, colors, and screen positions that can be distracting or difficult to read. MPV provides a dedicated setting called sub-ass-override that allows users to bypass these embedded author styles. This guide explains how to use the strip parameter in MPV to completely remove custom ASS styling and render subtitles as standard, readable text using your preferred player defaults.

What Does sub-ass-override=strip Do?

By default, MPV renders ASS subtitles according to the formatting defined inside the subtitle script. Setting --sub-ass-override=strip completely strips out all ASS-specific override tags, style definitions, and positioning rules. This effectively converts the ASS subtitles into plain text, similar to standard SRT files, and applies MPV's global subtitle rendering options.

Applying the Option via Command Line

To test the setting on a single file without modifying your permanent configuration, pass the flag directly in your terminal or command prompt:

mpv --sub-ass-override=strip "video.mkv"

Applying the Option Permanently in mpv.conf

To strip custom ASS styling automatically on every video you watch, add the option to your MPV configuration file (mpv.conf).

  1. Locate or create your mpv.conf file:

    • Linux/macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf (or inside a portable_config folder in your MPV directory)

  2. Add the following line to the file:

sub-ass-override=strip
  1. Save the file and restart MPV.

Customizing the Stripped Subtitle Appearance

Once custom styles are stripped, the subtitles inherit MPV's default styling settings. You can customize the look of these subtitles by adding additional style rules to your mpv.conf:

# Strip custom styles
sub-ass-override=strip

# Define custom plain text styling
sub-font="sans-serif"
sub-font-size=46
sub-color="#FFFFFFFF"
sub-border-color="#FF000000"
sub-border-size=2.5
sub-shadow-offset=1
sub-shadow-color="#33000000"
sub-margin-y=30

Toggling the Setting at Runtime

If you only want to strip styles occasionally while a video is playing, you can bind a key in your input.conf file to cycle between default rendering and stripped rendering:

k cycle-values sub-ass-override "strip" "no"

Pressing k will switch between the stripped plain text subtitles and the original stylized ASS subtitles.
