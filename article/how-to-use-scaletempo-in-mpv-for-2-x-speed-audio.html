How to Use Scaletempo in mpv for 2x Speed Audio

Watching videos at accelerated speeds often introduces robotic distortion, stuttering, or unnatural pitch shifts. By using the scaletempo and scaletempo2 audio filters in the mpv media player, you can scale playback speed up to 2x or higher while preserving the original audio pitch and maximizing speech clarity. This guide explains how to apply and fine-tune these filters temporarily through the command line or permanently via configuration files.

Understanding Scaletempo vs. Scaletempo2

mpv offers two primary filters for pitch-preserved tempo scaling:

  • scaletempo: The classic time-stretching filter based on the WSOLA (Waveform Similarity Overlap-Add) algorithm. It works well across various media types and allows detailed manual tweaking.
  • scaletempo2: A modernized implementation based on Chromium’s audio stretcher. It is specifically optimized for voice intelligibility at higher playback rates, making it ideal for podcasts, lectures, and tutorials played at 2x speed.

Enabling the Filter via Command Line

To test the filter on a single video without modifying permanent configuration files, pass the --af (audio filter) flag in your terminal:

mpv --af=scaletempo2 --speed=2.0 "video.mp4"

If you prefer the original scaletempo engine, execute:

mpv --af=scaletempo --speed=2.0 "video.mp4"

Applying Scaletempo Permanently in mpv.conf

To ensure every video opened in mpv maintains proper audio processing during speed changes, add the filter to your mpv.conf configuration file.

  1. Locate or create your mpv.conf file:

    • Linux/macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf or inside the portable_config directory next to mpv.exe.

  2. Add the following line to default to scaletempo2 for speed scaling:

# Use high-quality tempo scaling
af=scaletempo2

Fine-Tuning Filter Parameters for 2x Speed

If speech sounds choppy or echoey at 2x speed, you can adjust the algorithmic window sizes directly.

Tuning scaletempo2

The scaletempo2 filter accepts two primary parameters: search-interval (in milliseconds) and window-size (in milliseconds). Adjusting these can eliminate stuttering during fast speech:

af=scaletempo2=search-interval=30:window-size=60
  • search-interval: Lower values provide higher responsiveness to rapidly changing speech patterns.
  • window-size: Higher values improve audio smoothness at high speeds, while lower values reduce hollow echo effects.

Tuning Classic scaletempo

If you use classic scaletempo, adjust stride, overlap, and search:

af=scaletempo=stride=14:overlap=0.34:search=14
  • stride: The length (in milliseconds) of each audio segment. Setting this around 14ms provides a good balance between processing overhead and smoothness.
  • overlap: The percentage of the stride that overlaps with adjacent slices. The default is 0.20, but increasing it to 0.34 or 0.50 produces smoother transitions at 2x speed.
  • search: The search window (in milliseconds) used to align overlapping waveforms. Matching the stride length helps align speech transients naturally.

Controlling Playback Speed During Playback

Once the filter is loaded, use mpv's default keybindings to adjust speed dynamically during playback:

  • [ : Decrease speed by 10%.
  • ] : Increase speed by 10%.
  • { : Halve current speed.
  • } : Double current speed.
  • Backspace : Reset speed back to normal (1.0x).
