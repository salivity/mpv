Apply a 3D LUT in mpv for Color Correction

Applying a custom 3D Look-Up Table (LUT) in mpv allows users to achieve precise display calibration, correct color spaces, or implement cinematic color grading during video playback. This guide details how to configure mpv to load standard .cube files using configuration files, select a compatible video output driver, and optionally set up keyboard shortcuts to toggle the LUT on and off during playback.

1. Prepare Your 3D LUT

mpv natively supports standard Adobe 3D LUT files using the .cube extension. Ensure your calibration or creative LUT is exported in this format. For convenience, place the .cube file inside your mpv configuration folder:

  • Linux/macOS: ~/.config/mpv/
  • Windows: %APPDATA%\mpv\

2. Enable a Compatible Video Output

3D LUT processing requires mpv's GPU-accelerated video output drivers. Open your mpv.conf file in a text editor and specify gpu or gpu-next as your video output (VO):

vo=gpu-next
gpu-api=auto

gpu-next is recommended for newer mpv builds, but vo=gpu also supports LUT processing.

3. Load the LUT Automatically

To load the 3D LUT automatically every time mpv starts, add the lut option to your mpv.conf file followed by the path to your .cube file:

Linux / macOS:

lut="~/.config/mpv/calibration.cube"

Windows:

lut="C:/Users/Username/AppData/Roaming/mpv/calibration.cube"

Note: On Windows, use forward slashes (/) in the file path to avoid escape-character errors.

4. Toggle the LUT with a Hotkey (Optional)

If you prefer to switch the LUT on and off during playback rather than forcing it permanently, map a toggle key in your input.conf file instead of (or in addition to) setting it in mpv.conf:

b cycle-values lut "C:/path/to/your/lut.cube" ""

Pressing the b key during playback will alternate between loading your specified LUT and setting the parameter to an empty string, effectively toggling the color correction on and off.

5. Verify the Application

Launch any video file with mpv via the terminal or command prompt:

mpv video.mp4

You can confirm the LUT is active by pressing Shift + I to open mpv's on-screen statistics display, where active shaders and GPU processing filters are listed.
