Can mpv Play DVD ISO Files Directly?

The mpv media player fully supports playing DVD ISO image files directly without requiring you to unpack or mount them first. Thanks to its underlying integration with FFmpeg and DVD navigation libraries, mpv can read the disc structure, audio tracks, subtitles, and video streams directly from the raw disc image. This guide explains how to open DVD ISOs in mpv, how to navigate their menus, and what to do if you encounter playback issues.

How to Open a DVD ISO in mpv

Playing a DVD ISO file in mpv is as straightforward as opening any standard video file.

  • Drag and Drop: Drag the .iso file directly onto an open mpv window.
  • Graphical Interface: Right-click the .iso file in your operating system's file manager, select Open With, and choose mpv.
  • Command Line: Run the player from your terminal or command prompt by passing the file path: 
    mpv movie.iso

When opened this way, mpv automatically mounts the filesystem in memory and starts playing the main title or the first available title on the virtual disc.

Enabling DVD Menus and Title Navigation

By default, opening an ISO directly often bypasses the interactive DVD menu to jump straight to the video content. If you want full access to the interactive DVD menus, audio selection screens, and chapter listings, use the dvdnav:// protocol:

mpv dvdnav:// --dvd-device=movie.iso

Using dvdnav:// allows you to interact with the DVD menu using your keyboard. You can navigate menu buttons using the arrow keys and activate selections using the Enter key.

If you prefer skipping menus entirely but want to play a specific title from the disc, you can use the standard dvd:// syntax:

mpv dvd://2 --dvd-device=movie.iso

(Replace 2 with the specific title track number you wish to play).

Technical Requirements and Dependencies

For mpv to read DVD ISO files, it relies on standard media libraries that are included in almost all official mpv builds:

  • libdvdread: Allows the software to read the DVD Video structure directly from the ISO format.
  • libdvdnav: Provides support for DVD menu navigation, multi-angle scenes, and button interactions.

If you are using pre-compiled binaries for Windows, macOS (via Homebrew), or standard Linux distribution packages (such as Debian, Ubuntu, Fedora, or Arch), support for these libraries is enabled by default. If you built mpv from source, ensure that libdvdread and libdvdnav were installed on your system prior to compiling.
