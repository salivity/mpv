Extract High-Quality PNG Frames Using mpv

This guide explains how to capture the exact current frame of a video as a high-quality, lossless PNG using the mpv media player. It covers the interactive shortcut commands to use during playback, the permanent configuration options to guarantee the highest image fidelity, and a headless command-line method to extract a specific frame instantly.

The In-Player Screenshot Command

While playing a video in mpv, you can execute screenshot commands directly. Open the mpv console by pressing the backtick key (`) and type:

screenshot video
  • video ensures the screenshot contains only the raw video frame at its source resolution, bypassing on-screen display (OSD) elements, UI overlays, and subtitles.
  • If you want subtitles included, use screenshot subtitles.
  • To save directly to a custom file name, run: 
    screenshot-to-file "frame.png" video

Configuring mpv for Maximum Quality PNGs

By default, mpv may output lower-bit-depth images or JPEG formats depending on your system configuration. To force maximum quality PNG output every time you capture a frame, add the following parameters to your mpv.conf file (located in ~/.config/mpv/ on Linux/macOS or %APPDATA%/mpv/ on Windows):

# Use PNG as the output format
screenshot-format=png

# Use highest bit depth supported by the source (e.g., 10-bit or 12-bit)
screenshot-high-bit-depth=yes

# PNG compression level (0-9). 0 is uncompressed, 9 is highest compression.
# PNG compression is lossless, so quality remains identical, but lower values save faster.
screenshot-png-compression=7

# Apply correct color space tags to the PNG file
screenshot-tag-colorspace=yes

# Template for naming screenshots: Title-Timestamp
screenshot-template="%F-%P"

# Save screenshots to a specific directory (optional)
screenshot-directory="~/Pictures/mpv_screenshots"

Once added to mpv.conf, simply pressing Shift + s during playback will capture the clean video frame without subtitles, and s will capture it with subtitles.

Extracting a Frame via the Terminal (Headless Mode)

If you want to extract a frame from a specific timestamp without keeping the player window open, run the following terminal command:

mpv "input_video.mp4" --no-audio --start=00:01:23.456 --frames=1 --vo=image --vo-image-format=png --vo-image-high-bit-depth=yes
  • --no-audio: Disables audio processing for faster execution.
  • --start=00:01:23.456: Jumps to the exact timestamp (HH:MM:SS.mmm).
  • --frames=1: Terminates the player immediately after rendering one frame.
  • --vo=image: Directs video output to the image renderer instead of your screen.
  • --vo-image-format=png: Forces the rendered frame into PNG format.
