Adjust OSD Bar Width and Height in mpv

This guide explains how to customize the size of the on-screen display (OSD) progress bar in the mpv media player. By adjusting specific geometry properties in your configuration file, you can easily control both the width and height of the bar to fit your visual preferences.

Locate or Create mpv.conf

To make persistent changes, you must add the sizing options to your mpv.conf configuration file. The file is typically located in:

  • Linux and macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%/mpv/mpv.conf (or inside a portable_config folder next to mpv.exe)

If the file does not exist, create a plain text file named mpv.conf in that directory.

Modify OSD Bar Dimensions

mpv controls the size of the OSD bar using two main properties, both of which accept values as percentages of the screen dimensions:

  • osd-bar-w: Sets the width of the bar as a percentage of the screen width (default is 75).
  • osd-bar-h: Sets the height of the bar as a percentage of the screen height (default is 3.125).

Open mpv.conf in any text editor and add your desired dimensions:

# Set OSD bar width to 90% of the window width
osd-bar-w=90

# Set OSD bar height to 2% of the window height
osd-bar-h=2

Adjusting Vertical Position (Optional)

Changing the bar's height often requires adjusting its placement so it does not overlap with other interface elements or sit too close to the edge. You can use osd-bar-align-y to move the bar vertically:

  • -1 places the bar at the top edge.
  • 0 centers the bar vertically.
  • 1 places the bar at the bottom edge.

Example:

# Move the bar closer to the bottom edge
osd-bar-align-y=0.9

Testing via Command Line

You can test different sizes from your terminal or command prompt before saving them to your configuration file by passing them as arguments:

mpv --osd-bar-w=50 --osd-bar-h=1.5 "path/to/video.mp4"
