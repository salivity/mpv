Ignore input.conf in mpv for Default Keybindings

When troubleshooting keymap conflicts or verifying factory controls in the mpv media player, you do not need to delete or rename your custom configuration files. By utilizing built-in command-line flags, you can instruct mpv at launch to bypass your user-defined input.conf file entirely and fall back to its standard out-of-the-box keybindings for that specific session.

Method 1: Override the input.conf Path

The most direct way to ignore your custom keybinds while keeping the rest of your settings (such as your mpv.conf video and audio options) intact is to override the input file path using an empty string or the null device.

Run mpv from your terminal or command prompt with the --input-conf flag set to empty:

mpv --input-conf="" "video_file.mp4"

If an empty string is not supported by your shell or operating system, point the flag directly to your system's null device:

  • Linux and macOS: 
    mpv --input-conf=/dev/null "video_file.mp4"
  • Windows: 
    mpv --input-conf=NUL "video_file.mp4"

Because mpv finds an empty configuration file, it will not load any of your custom shortcuts and will automatically revert to its internal factory default keybindings.

Method 2: Launch mpv with All Configurations Disabled

If you want to ensure that no configuration scripts, user profiles, or configuration files (mpv.conf and input.conf) interfere with your testing, use the --no-config flag:

mpv --no-config "video_file.mp4"

This starts mpv in a completely vanilla state. It is especially useful if you have script bindings or profiles that alter keys outside of your standard input.conf.

Verifying Built-in Defaults

By default, mpv keeps its internal bindings active underneath your custom bindings. If you previously used the --no-input-default-bindings setting inside your mpv.conf to wipe built-in controls, you must ensure default bindings are explicitly enabled when testing:

mpv --input-conf="" --input-builtin-bindings=yes "video_file.mp4"

Once the player launches, standard default hotkeys—such as [ and ] for speed adjustment, o for showing progress, or 9 and 0 for volume control—will function according to default specifications without modifying your saved disk files.
