Check Hardware Decoder in MPV During Playback

Verifying which hardware decoder mpv uses is essential for troubleshooting performance issues, high CPU usage, and playback stutter. This guide explains how to quickly identify the active hardware decoding method—such as NVDEC, VA-API, or D3D11VA—using mpv’s built-in on-screen statistics display or through terminal output during playback.

Method 1: Use the On-Screen Statistics Overlay (Fastest)

The easiest way to check the active hardware decoder without leaving the video player is through the native statistics screen.

  1. Open your video with mpv.
  2. Press Shift + I (capital I) on your keyboard. This toggles the persistent statistics overlay. Alternatively, press lowercase i to display the information temporarily.
  3. Look for the hwdec or Hardware decoding line:
    • If hardware acceleration is active: You will see the specific API currently in use (e.g., nvdec, vaapi, d3d11va, or videotoolbox), often followed by the active hardware surface format (such as nv12 [hw]).
    • If software decoding is active: The field will display no or will show the software decoder codec directly (such as avcodec: h264), indicating your CPU is handling the video decoding.
  4. Press Shift + I again to dismiss the overlay.

Method 2: Check the Terminal Status Line

If you launch mpv from a command-line interface (such as Bash, Zsh, PowerShell, or Command Prompt), mpv prints real-time playback state to the console.

  1. Launch your media file from the terminal: 
    mpv video.mp4
  2. Observe the status line at the bottom of the terminal window while the video plays.
  3. Look at the VO: (Video Output) and decoder indicators:
    • A working hardware decoder typically displays the backend tag directly in the status line, such as: VO: [gpu] 1920x1080 nv12 [hw]
    • If it falls back to software, it displays a standard pixel format without the [hw] flag (such as yuv420p).

Method 3: Use Verbose Logging

If the overlay indicates that hardware decoding is not active, you can inspect why a specific hardware decoder failed to load by enabling verbose logs.

  1. Run mpv with the verbose flag targeting the hardware decoding module: 
    mpv -v video.mp4
  2. Filter or scan the output for lines containing vd or hwdec: 
    mpv -v video.mp4 | grep -i hwdec
  3. The output will explicitly list the attempts to initialize decoders:
    • Successful initialization: Using hardware decoding: nvdec (or your platform equivalent).
    • Failed initialization: Hardware decoding failed, falling back to software decoding.

Common Decoder Types

  • d3d11va / dxva2: Microsoft Windows native hardware APIs.
  • vaapi: Linux hardware API primarily for Intel and AMD GPUs.
  • nvdec / vdpau: NVIDIA proprietary APIs on Linux and Windows.
  • videotoolbox: Apple macOS native hardware API.
