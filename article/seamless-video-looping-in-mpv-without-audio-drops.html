Seamless Video Looping in mpv Without Audio Drops

Achieving seamless video looping in mpv without dropping audio frames is possible, but it requires tuning specific settings beyond the basic loop command. By default, mpv reinitializes its demuxer and decoder pipelines when a file restarts, causing a momentary silence or micro-stutter. This article outlines the specific configuration parameters and techniques needed to ensure continuous, gapless audio and video playback at the loop point.

The Cause of Audio Gaps

When using the standard --loop-file=inf or --loop=inf options, mpv reaches the end-of-file (EOF), clears its audio buffer, flushes the decoders, and reopens the media stream. This flush-and-reload cycle creates a noticeable hiccup or dropped audio frames, even on high-performance systems.

Configuration for Gapless Playback

To minimize or eliminate the gap during playback loops, apply the following configuration parameters via your mpv.conf file or pass them as command-line arguments:

# Enable gapless audio processing
gapless-audio=exact

# Increase audio buffer to prevent underruns
audio-buffer=0.5

# Ensure playlist prefetching is active
prefetch-playlist=yes

# Loop the file continuously
loop-file=inf

Explanation of Settings

  • gapless-audio=exact: Forces mpv to use an audio decoder pipeline that does not flush or reinitialize between file restarts if the audio format remains identical. If exact causes compatibility issues with your specific audio driver, you can use yes as an alternative.
  • audio-buffer=0.5: Allocates a larger buffer (in seconds) to bridge any slight delay caused by demuxer seeking at the loop boundary, preventing buffer underruns.
  • prefetch-playlist=yes: Directs mpv to begin demuxing the start of the file before playback of the current instance finishes.

Command-Line Execution

To run mpv directly with these options from the terminal:

mpv --loop-file=inf --gapless-audio=exact --prefetch-playlist=yes --audio-buffer=0.5 video.mp4

The EDL Alternative for Zero-Latency Loops

If hardware limitations or video codec constraints still introduce a micro-drop, use mpv's internal EDL (Edit Decision List) format. An EDL file tricks the player into treating multiple loops as a single continuous file, bypassing decoder resets entirely.

Create a plain text file named loop.edl containing the following structure:

# mpv EDL v0
video.mp4,0,30
video.mp4,0,30
video.mp4,0,30

Replace video.mp4 with the file path and adjust 0,30 to match the file's start and end timestamps in seconds. Loading mpv loop.edl will treat the transitions as simple timeline seeks rather than file restarts, eliminating dropped frames.
