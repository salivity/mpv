Customizing the mpv Interface with osc.lua

The osc.lua script is the core Lua script responsible for generating and managing the default On Screen Controller (OSC) in the mpv media player. By reading user preferences, tracking playback states, and rendering graphical controls like the seekbar, volume slider, and playback buttons, osc.lua defines how users interact visually with mpv. This article explains the exact role of osc.lua, how it interfaces with mpv’s configuration system, and how users can modify it to completely overhaul their graphical user interface.

The Role of osc.lua in mpv

By default, mpv is designed to be a minimal, keyboard-driven media player with no traditional window chrome or static control panels. To provide basic mouse-driven navigation, mpv embeds a built-in Lua script named osc.lua.

Whenever the mouse moves over the player window, osc.lua activates and renders an interactive overlay using the Advanced SubStation Alpha (ASS) subtitle format. It dynamically displays:

  • The seek bar and chapter markers.
  • Playback controls (play, pause, skip, playlist navigation).
  • Audio track, subtitle track, and video track selectors.
  • Window management icons (minimize, maximize, close).
  • Playback metadata, such as current timestamp, remaining time, and media title.

Configuration vs. Direct Script Modification

Customizing the OSC typically happens at two distinct levels: simple configuration and complete script replacement.

1. Configuration via osc.conf

For standard adjustments, users do not need to modify osc.lua directly. mpv allows users to pass options to the script using a configuration file located at ~~/script-opts/osc.conf. Through this file, you can modify built-in properties such as:

  • Layouts: Switching between pre-programmed layouts such as bottombar, topbar, box, or slim.
  • Timers: Adjusting fadeduration, hidetimeout, and showwindowed properties to control when the interface appears and fades away.
  • Scaling: Modifying scalewindowed and scalefullscreen to scale the controller dynamically based on display resolution.

2. Advanced Customization via Custom osc.lua

When predefined layouts and basic styling are insufficient, osc.lua can be extracted, rewritten, and loaded as a custom user script.

To override the built-in controller:

  1. Disable the internal OSC by adding osc=no to the main mpv.conf file.
  2. Obtain a copy of the stock osc.lua from the official mpv source repository.
  3. Place the modified script into the mpv scripts/ directory (for example, ~/.config/mpv/scripts/osc.lua on Linux or %APPDATA%/mpv/scripts/osc.lua on Windows).

What You Can Modify in osc.lua

Because osc.lua is an uncompiled Lua script running through mpv’s internal Lua 5.1 / LuaJIT interpreter, modifying the file offers unrestricted control over the interface:

  • Visual Design and Geometry: The script uses ASS vector drawings and formatting tags (such as \pos, \an, \bord, and \1c) to draw the interface. Modifying these strings lets you alter colors, corner radii, borders, transparency, and button shapes.
  • Layout Structures: You can reposition existing UI elements, eliminate components you do not use (such as window title bars or chapter ticks), or create entirely new layout algorithms that respond to window resizing.
  • Custom Interactive Controls: By tapping into the mp scripting API, you can add custom buttons to execute arbitrary mpv commands, run shell commands, load shaders, or trigger other user-installed scripts.
  • Event Handling and Logic: The script dictates how elements react to specific mouse behaviors, such as hover states, mouse-wheel scrolling for volume or seeking, and right-click secondary actions.
