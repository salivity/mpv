Fix mpv Window Position on Multiple Monitors

By default, mpv does not automatically persist its window coordinates when closed, often causing it to reopen on your primary display rather than your preferred monitor in a multi-display setup. This article explains how to resolve the issue using built-in options in your mpv.conf configuration file, such as the screen and geometry parameters, as well as how to use a lightweight Lua script to automatically save and restore your exact window position on exit.

Locate Your mpv.conf File

Before applying any fixes, open your mpv configuration directory:

  • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config folder if using a portable build)
  • Linux / macOS: ~/.config/mpv/mpv.conf

If the mpv.conf file does not exist, create it as a plain text file.

Method 1: Target a Specific Monitor by Index

If you consistently want mpv to open or fullscreen on a specific screen, you can assign the monitor directly in your configuration file.

  1. Open mpv.conf.
  2. Add the following lines:
# Specify which monitor to launch mpv on (0 is typically the primary display, 1 is secondary)
screen=1

# If launching in fullscreen, specify the target display
fs-screen=1
  1. Save the file. Change the number (0, 1, 2, etc.) depending on which display you want mpv to target.

Method 2: Lock Window Position Across Virtual Desktops

In a multi-monitor desktop arrangement, secondary monitors exist at specific coordinate offsets relative to the primary display. You can define exact starting coordinates using the geometry setting.

  1. Determine your monitor layout coordinates (for example, if your primary monitor is 1920x1080 and your secondary monitor sits to the right, the secondary monitor starts at X-coordinate +1920).
  2. Add the geometry property to mpv.conf:
# Syntax: <width>x<height>+<x-offset>+<y-offset>
# Example: Position window on a 1080p monitor placed to the right of the primary display
geometry=+1920+0
  1. Save the file. mpv will now default to those exact multi-monitor coordinates whenever a window is initialized.

Method 3: Automatically Save and Restore Dynamic Window Positions

If you frequently move mpv between monitors and need it to dynamically remember where it was closed, you must use a Lua script, as mpv does not save window geometry by default.

  1. Navigate to your mpv configuration directory.
  2. Inside, open or create a folder named scripts.
  3. Create a new file named remember-geometry.lua inside the scripts folder.
  4. Add the following code:
local utils = require 'mp.utils'

local function save_geometry()
    local geo = mp.get_property("geometry")
    local screen = mp.get_property("screen")
    local width, height, x, y = mp.get_property_number("window-width"), mp.get_property_number("window-height"), mp.get_property_number("window-x"), mp.get_property_number("window-y")
    
    if x and y and width and height then
        local state_path = utils.split_path(mp.find_config_file("mpv.conf")) .. "last_geometry.conf"
        local file = io.open(state_path, "w")
        if file then
            file:write(string.format("geometry=%dx%d+%d+%d\n", width, height, x, y))
            file:close()
        end
    end
end

mp.register_event("shutdown", save_geometry)
  1. In your mpv.conf, include the auto-generated config file at the top:
include=~~/last_geometry.conf

Once configured, the script writes the current window dimensions and coordinate offsets upon closing, allowing mpv to reload into the identical position and monitor on its next launch.
