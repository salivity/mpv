How to Mute MPV with a Global Hotkey

Controlling mpv when its window is minimized or unfocused requires bridging your operating system's global shortcut manager with mpv's built-in Inter-Process Communication (IPC) server. By enabling the IPC server in mpv's configuration file, mpv listens for JSON-formatted commands through a local socket or named pipe. This guide walks you through enabling IPC in mpv and assigning a system-wide hotkey to toggle mute on both Linux and Windows.

Step 1: Enable IPC in MPV

To allow external scripts to send commands to mpv, you must tell mpv to create an IPC server upon startup.

  1. Locate or create your mpv.conf file:

    • Linux/macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf

  2. Add the appropriate IPC socket configuration line:

    For Linux/macOS:

    input-ipc-server=/tmp/mpvsocket

    For Windows:

    input-ipc-server=\\.\pipe\mpvsocket

  3. Save and close the file.

Step 2: Set Up Global Hotkeys on Linux

On Linux, you can interact with unix domain sockets using socat.

1. Install socat

Ensure socat is installed on your distribution:

  • Ubuntu/Debian: sudo apt install socat
  • Arch Linux: sudo pacman -S socat
  • Fedora: sudo dnf install socat

2. Create the Mute Command

The command to cycle the mute state in mpv is:

echo '{ "command": ["cycle", "mute"] }' | socat - /tmp/mpvsocket

3. Bind the Command to a Hotkey

  • GNOME: Open Settings > Keyboard > View and Customize Shortcuts > Custom Shortcuts. Add a new shortcut, paste the socat command above into the Command field, and assign your desired key combination.
  • KDE Plasma: Open System Settings > Shortcuts > Custom Shortcuts. Add a new Global Shortcut > Command/URL, set the action to the socat command, and assign a trigger.
  • i3/Sway: Add the following line to your config file: 
    bindsym $mod+m exec echo '{ "command": ["cycle", "mute"] }' | socat - /tmp/mpvsocket

Step 3: Set Up Global Hotkeys on Windows

On Windows, AutoHotkey (AHK) is the most reliable tool for sending data to mpv's named pipe without bringing the window into focus.

1. Install AutoHotkey

Download and install AutoHotkey (v1.1 or v2).

2. Create an AutoHotkey Script

Create a new file named mpv_mute.ahk and paste the following script (compatible with AutoHotkey v1.1):

; Win+M to toggle mute in MPV
#m::
pipe := FileOpen("\\.\pipe\mpvsocket", "w")
if (IsObject(pipe)) {
    pipe.Write('{ "command": ["cycle", "mute"] }`n')
    pipe.Close()
}
return

(Note: #m represents the Windows Key + M combination. You can replace #m with any combination, such as ^!m for Ctrl + Alt + M.)

3. Run the Script

  1. Double-click mpv_mute.ahk to launch it.
  2. Place a shortcut to this .ahk file in your Windows Startup folder (shell:startup in the Run dialog) to have it run automatically upon login.

Step 4: Verification

  1. Launch any audio or video file with mpv.
  2. Focus on another application (such as a web browser or text editor).
  3. Press your configured hotkey. The audio will toggle between muted and unmuted instantly, confirming that mpv is accepting global commands regardless of window focus.
