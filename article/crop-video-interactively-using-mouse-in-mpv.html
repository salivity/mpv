Crop Video Interactively Using Mouse in mpv

By default, the mpv media player does not include a native, built-in feature to click and drag a crop area using your mouse. However, mpv provides full support for interactive mouse cropping through its extensible Lua scripting engine. By adding a simple, community-developed Lua script to your mpv configuration, you can easily select a region of interest directly on the screen using mouse dragging and instantly crop the video playback.

Native mpv Behavior vs. Interactive Cropping

Out of the box, mpv handles cropping through command-line parameters or keybindings that pass values directly to FFmpeg’s lavfi filter (specifically the crop filter). While you can manually zoom, pan, or pass static coordinates like --vf=crop=w:h:x:y, mpv lacks an integrated graphical user interface to draw this bounding box with a mouse pointer.

To bridge this gap, mpv exposes an internal API that allows user scripts to capture mouse events, track cursor coordinates, and dynamically apply video filters during runtime.

How to Enable Mouse Cropping in mpv

To enable interactive mouse cropping, you must install a Lua script. The most widely used and reliable script for this task is crop.lua (originally created by user occivink).

  1. Locate Your mpv Configuration Directory:

    • Linux/macOS: ~/.config/mpv/
    • Windows: %APPDATA%/mpv/ or the directory where mpv.exe is located (if using a portable setup).

  2. Add the Script:

    • Inside your mpv configuration directory, create a subfolder named scripts if it does not already exist.
    • Download or create crop.lua inside that scripts/ folder.

  3. Using the Interactive Crop Tool:

    • Open any video file using mpv.
    • Press the default trigger key (typically c or C, depending on the script version) to enter crop mode.
    • Click and hold the left mouse button, drag a rectangle over the section of the video you want to keep, and release the button.
    • The video will immediately crop to the selected area.
    • To reset the crop and return to the original video dimensions, press the trigger key again or press the escape key.

Through this scripting method, mpv can match the interactive cropping capabilities of full graphical video editors while retaining its minimalist, lightweight interface.
