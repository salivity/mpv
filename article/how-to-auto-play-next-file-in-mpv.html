How to Auto Play Next File in MPV

By default, mpv only plays the specific media file you open and exits once playback finishes without loading the rest of the folder. This guide explains how to configure mpv to automatically load and play subsequent files in the same directory using the official autoload.lua script or via command-line arguments.

Method 1: Use the autoload.lua Script (Recommended)

The most seamless way to play the next file automatically is using autoload.lua, a script created by the mpv development team. When you open any single audio or video file, this script automatically scans the containing directory, sorts the media files, and populates your playlist with the remaining items.

Step 1: Create the Scripts Directory

If it does not already exist, create a scripts folder inside your mpv configuration directory:

  • Windows: %APPDATA%\mpv\scripts\ (or portable_config\scripts\ if using the portable version)
  • Linux & macOS: ~/.config/mpv/scripts/

Step 2: Download or Create autoload.lua

  1. Navigate to the official mpv GitHub repository's tools section or create a new file named autoload.lua inside your scripts directory.
  2. If creating it manually, paste the official script contents from mpv’s TOOLS/lua/autoload.lua.
  3. Save the file.

Once in place, mpv will load the script on startup. Opening any media file will automatically append the next files in the folder to the playlist in alphabetical order.

Method 2: Open the Entire Directory

If you do not want to install scripts, you can instruct mpv to load the whole folder directly rather than an individual file.

Via Command Line

Pass the directory path instead of a file name:

mpv /path/to/folder/

To start playback from a specific file within the terminal and queue the rest, use wildcards (Linux/macOS):

mpv ./*

Via Drag and Drop

Instead of dragging an individual video or audio file into the mpv window, drag and drop the entire folder into the player. Mpv will create a playlist containing all supported media files inside that folder and play them sequentially.

Useful Keybindings for Playlist Navigation

Once mpv is loading the rest of the folder into your playlist, use these default keyboard shortcuts to navigate:

  • > (Shift + .): Skip to the next file in the folder.
  • < (Shift + ,): Return to the previous file.
  • F8: View the full playlist on screen.
