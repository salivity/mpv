How to Limit Maximum Volume Boost in mpv

This guide explains how to restrict the software amplifier's maximum volume boost in the mpv media player. By configuring the volume-max property, you can prevent audio distortion, avoid accidental clipping, and stop mpv from amplifying audio beyond a level you find safe or comfortable.

The volume-max Setting

By default, mpv allows you to increase audio volume up to 130%, which introduces a 30% software amplification beyond the original source level. You can set an exact cap on this value using the volume-max parameter, which accepts a percentage value between 100.0 and 1000.0.

  • Setting volume-max=100 completely disables the software amplifier, ensuring the player never boosts audio louder than the file's native level.
  • Setting a custom value such as volume-max=150 limits the amplification to 150%.

Setting the Limit Permanently

To apply this limit permanently, add the option to your mpv.conf configuration file.

  1. Locate your mpv.conf file:

    • Linux & macOS: ~/.config/mpv/mpv.conf
    • Windows (Installed): %APPDATA%\mpv\mpv.conf
    • Windows (Portable): mpv\portable_config\mpv.conf

  2. Open the file in any plain text editor.

  3. Add the following line to disable boosting beyond standard volume:

    volume-max=100

    (Change 100 to your desired maximum ceiling, such as 110 or 125.)

  4. Save and close the file.

Setting the Limit from the Command Line

If you only want to set the cap for a single session or are running mpv from a script, pass the flag directly when launching the application:

mpv --volume-max=100 "filename.mkv"

Adjusting Volume Step Sizes (Optional)

If your volume keys jump too fast toward your limit, you can also control the step size in mpv.conf:

volume-max=100
volume=100
# Changes volume in 2% increments instead of default 5%
volume-step=2

Once saved, mpv will strictly respect your defined volume boundaries across all media playback.
