How to Disable Save Position on Quit in MPV

The save-position-on-quit feature in mpv automatically bookmarks your playback progress so that media files reopen precisely where you left off. This article explains the purpose and mechanics of this feature, how to turn it off globally or temporarily, and how to remove existing saved playback positions from your system.

Purpose of save-position-on-quit

The save-position-on-quit option is designed for convenience, especially when viewing long-form media such as movies, lectures, or television series. When enabled, mpv saves playback metadata to a local cache folder whenever the player exits. This metadata includes:

  • The exact timestamp (playback position) where playback was stopped.
  • Selected audio and subtitle tracks.
  • Certain custom playback adjustments, such as volume or playback speed.

When you reopen the same file, mpv cross-references its file path or hash with the saved cache and automatically resumes playback from that position instead of starting from the beginning.

How to Disable save-position-on-quit

Depending on how mpv is configured on your system, you can disable this behavior globally using the configuration file or temporarily using command-line flags.

1. Disable via mpv.conf (Permanent)

To turn off the feature for all future sessions, edit your mpv.conf file:

  • Linux / macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config folder if using a portable installation).

Open mpv.conf in a text editor and search for:

save-position-on-quit=yes

Change it to:

save-position-on-quit=no

Alternatively, if the line is present, you can simply delete it or comment it out by placing a # at the beginning of the line:

# save-position-on-quit=yes

Save the file and restart mpv.

2. Disable via Command Line (Temporary)

If you only want to disable position saving for a specific playback session without editing configuration files, use the --no-save-position-on-quit flag when launching mpv:

mpv --no-save-position-on-quit "filename.mkv"

You can also explicitly set the flag to no:

mpv --save-position-on-quit=no "filename.mkv"

3. Keyboard Shortcut Behavior

By default, mpv maps the Shift + Q key combination to quit-watch-later. Even if save-position-on-quit is disabled in your configuration, exiting the player using Shift + Q will still save the position. To exit without saving, use lowercase q or close the window.

Clearing Previously Saved Positions

Disabling save-position-on-quit stops mpv from recording new positions, but files with already-recorded states may still resume where you left off. To clear past states, delete the contents of the watch_later directory:

  • Linux / macOS: ~/.local/state/mpv/watch_later/ or ~/.config/mpv/watch_later/
  • Windows: %APPDATA%\mpv\watch_later\

Deleting the files inside this directory resets all saved positions, ensuring all media starts from the beginning.
