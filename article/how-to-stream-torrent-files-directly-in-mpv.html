How to Stream Torrent Files Directly in MPV

MPV cannot natively stream torrent files out of the box because it lacks a built-in BitTorrent client to handle peer-to-peer swarms. However, you can seamlessly stream torrents in MPV without downloading them completely first by pairing the player with sequential streaming tools such as WebTorrent CLI, Peerflix, or dedicated MPV plugins.

Why MPV Cannot Play Torrents Natively

MPV is designed to process local media files, network pipes, and direct media streams over protocols like HTTP, RTSP, or HLS (often assisted by yt-dlp). The BitTorrent protocol operates differently: it downloads pieces of a file out of order from multiple peers across a decentralized swarm. Because media players require sequential data to decode audio and video frames continuously, MPV cannot read a standard torrent file or magnet link without a middle layer requesting the file pieces sequentially.

The Solution: Sequential Streaming Tools

To stream torrents directly to MPV, you use a utility that downloads the pieces in sequential order and provides a local stream address or pipes the data directly into MPV.

1. WebTorrent CLI

WebTorrent CLI is a popular Node.js tool that fetches torrent pieces sequentially and automatically opens them in your media player.

  • Installation: Requires Node.js. Run npm install -g webtorrent-cli.
  • Usage: 
    webtorrent "magnet:?xt=urn:btih:..." --mpv
    You can also pass a local .torrent file path instead of a magnet link.

2. Peerflix

Peerflix is another widely used tool specifically built for streaming torrents to video players.

  • Installation: Requires Node.js. Run npm install -g peerflix.
  • Usage: 
    peerflix "magnet:?xt=urn:btih:..." --mpv

3. MPV WebTorrent Scripts

If you prefer opening magnet links or .torrent files directly within MPV without using external terminal commands each time, you can install community-made Lua or JavaScript hooks (such as webtorrent-mpv-hook). Once placed in your MPV scripts directory, you can pass magnet links directly to the mpv command or drag-and-drop torrent files into the MPV window.

Key Considerations for Torrent Streaming

  • Swarm Health: Streaming requires high-speed sequential delivery. If a torrent has very few seeders or low upload bandwidth, playback will frequently buffer or fail.
  • Initial Buffer: Expect a short delay before playback begins while the tool connects to peers and buffers the file header and initial video chunks.
  • Disk Usage: Most tools cache the downloaded portions into a temporary directory on your drive. These files are typically cleared automatically when playback finishes, depending on the tool's configuration settings.
