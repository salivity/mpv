How to Enable Dynamic Range Compression in mpv

This guide explains how to apply dynamic range compression (DRC) during media playback in the mpv media player. By leveraging integrated audio filters, you can effectively balance the volume difference between quiet dialogue and loud sound effects, preventing the need to constantly adjust volume levels. The sections below provide the exact command-line syntax, recommended filter parameters, and instructions for setting DRC permanently in your configuration file.

The Command

To apply dynamic range compression during playback from the command line, pass the acompressor audio filter to mpv using the --af flag:

mpv --af=acompressor filename.mkv

For more aggressive compression that actively boosts quiet voices and suppresses explosions, specify custom parameters:

mpv --af=acompressor=threshold=-25dB:ratio=4:attack=200:release=1000 filename.mkv

Alternative: Dynamic Audio Normalizer

Another popular filter for evening out dynamic range is dynaudnorm (Dynamic Audio Normalizer). It dynamically normalizes audio levels over time:

mpv --af=dynaudnorm filename.mkv

Permanent Configuration

To apply compression automatically to all media playback without entering the flag each time, add the filter to your mpv.conf file:

af=acompressor=threshold=-21dB:ratio=4:attack=200:release=1000

Toggle Compression with a Keybind

To toggle dynamic range compression on and off while a video is playing, add the following line to your input.conf file:

n cycle_values af "acompressor=threshold=-21dB:ratio=4:attack=200:release=1000" ""

Pressing n during playback will toggle the compressor on and off.
