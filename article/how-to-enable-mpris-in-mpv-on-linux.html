How to Enable MPRIS in mpv on Linux

This guide explains how to enable the MPRIS (Media Player Remote Interfacing Specification) plugin for the mpv media player on Linux. By following these steps, you will integrate mpv with your desktop environment, allowing you to view track information and control media playback using your desktop panel, lock screen, or keyboard media keys.

1. Install the mpv-mpris Plugin

Most major Linux distributions provide the mpv-mpris plugin directly through their official package repositories. Open your terminal and run the command corresponding to your distribution:

  • Ubuntu / Debian / Linux Mint:

    sudo apt install mpv-mpris

  • Arch Linux / Manjaro:

    sudo pacman -S mpv-mpris

  • Fedora:

    sudo dnf install mpv-mpris

  • openSUSE:

    sudo zypper install mpv-mpris

2. Manual Installation (Alternative)

If your distribution does not package mpv-mpris, you can install it manually:

  1. Download the latest mpris.so file from the official releases on GitHub.
  2. Create the mpv scripts directory if it does not already exist: 
    mkdir -p ~/.config/mpv/scripts
  3. Move the downloaded mpris.so file into that directory: 
    mv mpris.so ~/.config/mpv/scripts/

3. Verify the Installation

The plugin loads automatically whenever mpv launches. To confirm it is functioning:

  1. Play any audio or video file using mpv: 
    mpv /path/to/media/file.mp4
  2. Check your desktop environment's media controls (such as the GNOME Notification Center, KDE Plasma Media Player widget, or XFCE panel). The currently playing file should appear with playback controls.
  3. Alternatively, verify via the command line using playerctl: 
    playerctl -p mpv status

You can now pause, play, skip tracks, and adjust volume in mpv directly through your Linux desktop panel and hardware multimedia keys.
