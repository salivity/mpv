Pass Custom yt-dlp Arguments Through mpv

This guide explains how to pass custom yt-dlp command-line options directly through the mpv media player. By leveraging the --ytdl-raw-options flag, you can control video resolution, subtitle tracks, authentication cookies, and other backend extraction features directly from your terminal or within the mpv.conf configuration file.

Command-Line Syntax

To pass parameters from the terminal, use the --ytdl-raw-options option followed by a comma-separated list of key=value pairs:

mpv --ytdl-raw-options=KEY=VALUE,KEY2=VALUE2 "URL"

Rules for --ytdl-raw-options:

  • Remove Leading Dashes: Omit the leading -- from the yt-dlp parameter names (e.g., --cookies becomes cookies).
  • Options with Values: Separate the key and value with an equals sign (=).
  • Flags without Values: Set the key with an empty value using an equals sign and nothing after it (e.g., yes-playlist=).

Common CLI Examples

Specify Video Formats: Pass a custom format string to fetch specific video and audio streams:

mpv --ytdl-raw-options=format="bv*[height<=1080]+ba/b" "https://www.youtube.com/watch?v=example"

Use Authentication Cookies: Pass a browser cookie file or extract cookies from a browser for age-restricted or members-only videos:

mpv --ytdl-raw-options=cookies-from-browser=firefox "https://www.youtube.com/watch?v=example"

Fetch Subtitles: Download and display specific language subtitles automatically:

mpv --ytdl-raw-options=write-subs=,sub-langs="en.*,ja" "https://www.youtube.com/watch?v=example"

Ignore SSL Errors: Pass boolean flags that take no values:

mpv --ytdl-raw-options=no-check-certificates= "https://www.youtube.com/watch?v=example"

Configuration File Syntax (mpv.conf)

If you want these options applied permanently, add them to your mpv.conf file (located at ~/.config/mpv/mpv.conf on Linux/macOS or %APPDATA%/mpv/mpv.conf on Windows).

In the configuration file, omit the leading --:

# Set preferred video format
ytdl-raw-options=format="bestvideo[height<=1440]+bestaudio/best"

# Append additional options
ytdl-raw-options-append=cookies-from-browser=chrome
ytdl-raw-options-append=sub-langs=en
ytdl-raw-options-append=write-auto-subs=

Using ytdl-raw-options-append prevents multiple entries from overwriting one another and allows for organized, line-by-line configuration.
