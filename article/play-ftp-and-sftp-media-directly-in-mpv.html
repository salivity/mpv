Play FTP and SFTP Media Directly in mpv

mpv natively supports streaming media files directly from both FTP and SFTP servers by leveraging its underlying FFmpeg libraries. Standard FTP playback works out of the box on almost all installations, while direct SFTP playback depends on whether the underlying FFmpeg build was compiled with libssh support. This guide explains how to stream directly using standard URL syntax, how to verify protocol support, and how to handle playback if your build lacks native SFTP capabilities.

How mpv Handles Network Protocols

mpv relies on FFmpeg's libavformat to handle network protocols and file demuxing. Because of this integration, any network protocol supported by your local FFmpeg build is automatically accessible inside mpv without requiring additional plugins or extensions.

Streaming from an FTP Server

FTP playback is broadly supported by default across all standard mpv distributions. You can launch playback directly from your terminal by supplying the resource URL:

mpv ftp://hostname/path/to/video.mp4

For servers requiring authentication or non-standard ports, use standard URI encoding:

mpv ftp://username:password@hostname:21/path/to/video.mp4

Streaming from an SFTP Server

SFTP (SSH File Transfer Protocol) operates over an encrypted SSH transport layer. mpv supports direct SFTP streaming using the following syntax:

mpv sftp://username:password@hostname/path/to/video.mkv

If your SSH setup uses key-based authentication without passwords, mpv can often read the credentials directly if your SSH agent is active, allowing you to omit the password:

mpv sftp://username@hostname/path/to/video.mkv

Checking for Native SFTP Support

Because SFTP requires FFmpeg to be compiled with the optional libssh dependency, some minimalist or default operating system builds omit it. You can check if your system supports SFTP by querying FFmpeg directly:

ffmpeg -protocols | grep sftp

If sftp appears in the output list under input protocols, mpv can play SFTP URLs directly.

Alternatives if SFTP is Not Supported

If your mpv or FFmpeg binary does not support the sftp:// scheme, you can use one of two practical workarounds:

  1. Mount via SSHFS: Mount the remote server to a local directory using SSHFS, then open the file normally. This method preserves seeking functionality:

    sshfs user@hostname:/remote/media /mnt/remote
mpv /mnt/remote/video.mkv

  2. Pipe via SSH: Stream the file output directly through standard input over an SSH connection:

    ssh user@hostname "cat /path/to/video.mkv" | mpv -

    Note: Piping through standard input disables forward and backward seeking.
