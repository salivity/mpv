Force mpv CPU Decoding for Specific File Types

By default, the mpv media player can utilize your GPU via hardware acceleration to decode video, but this can cause stability or performance issues with certain formats. This guide explains how to use conditional profiles in your mpv.conf configuration file to automatically disable hardware acceleration and force software (CPU) decoding for specific file extensions or video codecs without affecting the rest of your media library.

Locate or Create Your Configuration File

To apply rules, open or create your mpv.conf file in the appropriate directory for your operating system:

  • Linux / macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%/mpv/mpv.conf (or inside the portable_config folder if using a portable build)

Ensure that your global hardware decoding setting is defined near the top of the file (for example, hwdec=auto).

Method 1: Force CPU Decoding by File Extension

If you want to disable GPU decoding based on the container format (such as .mkv, .webm, or .avi), use mpv's built-in file extension profiles.

Append the following syntax to the bottom of your mpv.conf:

[extension.webm]
hwdec=no

[extension.avi]
hwdec=no

Whenever mpv opens a .webm or .avi file, it will override the global setting and set hwdec=no, forcing the CPU to handle decoding.

Method 2: Force CPU Decoding by Video Codec

Targeting by file extension may not always be sufficient, as containers like .mkv can hold various codecs (e.g., AV1, HEVC, H.264). To force CPU decoding based on the actual video codec, use conditional profiles.

Add a profile with a profile-cond check to your mpv.conf:

[cpu-av1]
profile-cond=video_codec == 'av1'
hwdec=no

[cpu-hevc]
profile-cond=video_codec == 'hevc'
hwdec=no

You can combine multiple codecs into a single conditional rule using Lua operators:

[cpu-decode-codecs]
profile-cond=video_codec == 'av1' or video_codec == 'vp9'
hwdec=no

Verifying the Configuration

To verify that CPU decoding is active during playback:

  1. Open the file in mpv.
  2. Press Shift + I to display the playback statistics overlay.
  3. Look for the Decoder line. If CPU decoding is active, it will list the software decoder name (such as libdav1d or ffh264) without a [hw] tag appended to it.
