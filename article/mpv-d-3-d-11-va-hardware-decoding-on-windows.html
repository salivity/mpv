mpv D3D11VA Hardware Decoding on Windows

The mpv media player fully supports the Direct3D 11 Video Acceleration (D3D11VA) hardware video decoder on Windows systems. By utilizing D3D11VA, mpv offloads video decoding tasks directly to the graphics processing unit (GPU), drastically lowering CPU utilization, improving energy efficiency, and ensuring smooth playback for resource-intensive codecs such as H.264, HEVC (H.265), and VP9 at high resolutions like 4K and 8K.

How D3D11VA Works in mpv

D3D11VA is the native hardware acceleration API for modern Windows platforms (Windows 8 and newer). In mpv, hardware decoding can be handled in two distinct modes:

  1. Direct Mode (d3d11va): The decoded video frames remain entirely in GPU memory and are rendered directly via Direct3D. This provides the lowest latency, minimal CPU overhead, and optimal power efficiency.
  2. Copy-Back Mode (d3d11va-copy): The decoded frames are copied back from GPU memory into system RAM before rendering. While this introduces slightly higher memory bandwidth usage, it allows mpv to apply software-based video filters that require CPU processing.

Enabling D3D11VA

To enable D3D11VA, add the configuration options to your mpv.conf file or pass them as command-line arguments.

For optimal zero-copy rendering, pair the decoder with the Direct3D 11 rendering backend:

gpu-api=d3d11
hwdec=d3d11va

If you require video filters that do not support direct GPU rendering, configure copy-back mode instead:

hwdec=d3d11va-copy

Alternatively, setting hwdec=auto-safe or hwdec=auto will automatically select D3D11VA on modern Windows installations if supported by your hardware and driver configuration.

System Requirements and Verification

D3D11VA support requires Windows 8, Windows 10, or Windows 11, along with a compatible GPU (Intel, AMD, or NVIDIA) and up-to-date graphics drivers.

To verify that D3D11VA is active during video playback, press Shift + I to open mpv's on-screen statistics display. The "Hardware decoding" field will explicitly indicate d3d11va or d3d11va-copy alongside the active video codec.
