MPV Conditional Profiles by File Extension

Configuring conditional profiles in mpv allows you to automatically apply specific playback settings, video filters, or keybindings depending on the media file type being played. This guide explains how to define conditional profiles in your mpv.conf file by matching file extensions using mpv's Lua pattern-matching capabilities within the profile-cond property.

Locating the Configuration File

Before adding profiles, ensure you are editing the correct mpv.conf file for your operating system:

  • Linux / macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%/mpv/mpv.conf (or inside the portable_config directory if using a portable build)

If the file does not exist, create a blank text file named mpv.conf in that location.

Defining a Conditional Profile

In mpv, conditional profiles use the profile-cond property. This property evaluates a Lua expression and activates the profile automatically whenever the condition evaluates to true.

To match a file extension, use Lua's pattern-matching function on the filename or path property.

Basic Syntax for a Single Extension

Add a named profile block enclosed in brackets, followed by the profile-cond condition and the settings you want to apply:

[audio-files]
profile-cond=filename:match('%.mp3$') ~= nil
volume=80
audio-display=no

In this example:

  • filename:match('%.mp3$') searches the filename for .mp3 at the end of the string (where $ represents the end of the string and % escapes the dot).
  • ~= nil ensures the profile activates only when a match is found.

Matching Multiple Extensions

You can combine multiple file extension checks within a single condition using the Lua or operator:

[web-videos]
profile-cond=filename:match('%.mp4$') ~= nil or filename:match('%.webm$') ~= nil
loop-file=inf
hwdec=auto-safe

Alternatively, you can use Lua character classes to capture variations:

[image-viewer]
profile-cond=filename:match('%.jpe?g$') ~= nil or filename:match('%.png$') ~= nil
image-display-duration=5
pause=no

Case-Insensitive Matching

To ensure files with uppercase extensions (like .MKV or .MP4) are also matched, convert the filename to lowercase using :lower() before matching:

[mkv-settings]
profile-cond=filename:lower():match('%.mkv$') ~= nil
sub-auto=fuzzy
sub-visibility=yes

Profile Restoration

By default, settings modified by a conditional profile might persist when moving to the next item in a playlist if the next file does not override them. To ensure the previous state is restored when an extension condition no longer applies, set the profile-restore property at the top of your mpv.conf:

profile-restore=copy

With this setting enabled, mpv reverts any modified values back to their defaults when playing a file that does not match the active profile's condition.
