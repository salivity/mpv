How to Map mpv Mouse Buttons to Chapters

This guide explains how to map your mouse buttons to skip between previous and next chapters in the mpv media player. By adding specific key bindings to mpv's input.conf configuration file, you can utilize extra mouse buttons—such as standard side navigation buttons or scroll wheel combinations—to jump seamlessly across chapter markers.

Step 1: Locate or Create input.conf

mpv handles custom input mappings via a plain text file named input.conf. Depending on your operating system, this file is located in the mpv configuration directory:

  • Linux and macOS: ~/.config/mpv/input.conf
  • Windows: %APPDATA%\mpv\input.conf (typically C:\Users\<Username>\AppData\Roaming\mpv\input.conf)

If the mpv folder or the input.conf file does not exist, create them manually.

Step 2: Add the Key Bindings

Open input.conf in any text editor and add the commands to bind your preferred mouse buttons to chapter navigation.

Most modern mice feature side buttons (often used as "Back" and "Forward" in web browsers), which mpv identifies as MBTN_BACK and MBTN_FORWARD.

Add the following lines to map these side buttons:

MBTN_FORWARD add chapter 1
MBTN_BACK    add chapter -1
  • add chapter 1 advances playback to the next chapter.
  • add chapter -1 returns playback to the beginning of the current chapter or jumps to the previous chapter.

Alternative Mouse Bindings

If your mouse does not have side buttons, or if you prefer a different layout, you can map other mouse inputs:

Middle Mouse Click (Scroll Wheel Click):

MBTN_MID add chapter 1

Scroll Wheel with a Modifier Key (Shift):

Shift+WHEEL_UP   add chapter 1
Shift+WHEEL_DOWN add chapter -1

Right Click with a Modifier Key (Ctrl):

Ctrl+MBTN_RIGHT add chapter 1
Ctrl+MBTN_LEFT  add chapter -1

Step 3: Save and Verify

  1. Save and close the input.conf file.
  2. Open a media file containing chapter markers in mpv.
  3. Click the configured mouse buttons to confirm that playback jumps forward and backward through the chapters as expected.
