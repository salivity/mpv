Print Current Playback Timestamp to Terminal in MPV

This article provides a concise guide on how to print the exact timestamp of the current playback position to the terminal using the mpv media player. It covers the specific internal command used for standard output, how to bind this action to a keyboard shortcut, and alternative methods using command-line arguments and IPC sockets for automated scripting.

The Command: print-text

The mpv command that prints strings directly to stdout (the terminal window running mpv) is print-text. To output the exact current playback position, combine print-text with mpv's property expansion syntax using the ${time-pos} property:

print-text "${time-pos}"
  • ${time-pos} prints the current position in seconds with fractional precision (e.g., 84.321000).
  • ${playback-time} can be used instead if you prefer the standard HH:MM:SS human-readable format.

Method 1: Binding to a Key in input.conf

To output the timestamp whenever you press a key during playback, define the binding in your mpv input.conf file (located in ~/.config/mpv/input.conf on Linux/macOS or %APPDATA%/mpv/input.conf on Windows).

Add the following line to map the action to a key (such as t):

t print-text "${time-pos}"

Whenever you press t in the player window, mpv will print the current playback position in seconds directly to the terminal where the player was launched.

Method 2: Customizing the Terminal Status Line

If you want mpv to continuously show the exact timestamp in the terminal status line without pressing any keys, pass the --term-status-msg option when launching mpv:

mpv --term-status-msg='Current Time: ${time-pos}' video.mp4

This continuously overwrites the terminal status line with the exact raw second counter during playback.

Method 3: Querying the Timestamp via IPC

For external shell scripts and terminal automation, you can query the property dynamically using mpv's JSON IPC interface.

  1. Launch mpv with an IPC socket enabled:

    mpv --input-ipc-server=/tmp/mpvsocket video.mp4

  2. From another terminal window or script, send a command to read the property using socat and parse the output:

    echo '{ "command": ["get_property", "time-pos"] }' | socat - /tmp/mpvsocket

The response will return a JSON object containing the exact playback position in the data field.
