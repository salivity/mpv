How to Center the mpv Window on Launch

The mpv media player does have a dedicated parameter to center its video window upon launch, which is handled via the --geometry option. By specifying relative coordinate percentages, users can force the player window to appear directly in the middle of their display rather than relying on default window manager placement. This behavior can be triggered on a per-launch basis via the command line or applied permanently through the mpv.conf configuration file.

The Centering Parameter

To place the window in the center of the screen, use the value 50%:50% with the geometry parameter:

--geometry=50%:50%

When percentages are supplied for the horizontal (X) and vertical (Y) coordinates in mpv, the player aligns the center of the video window with that percentage of the screen space. Setting both values to 50% aligns the exact center of the window with the exact center of your monitor.

Command-Line Usage

To test or use the parameter for a single playback instance, append it to your launch command:

mpv --geometry=50%:50% video.mp4

Making the Behavior Permanent

To ensure mpv always launches in the center of your screen without typing the flag each time, add the setting to your mpv.conf configuration file:

  1. Locate or create your configuration file:
    • Linux/macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config directory if running portable mode).
  2. Open mpv.conf in a text editor.
  3. Add the following line:
geometry=50%:50%
  1. Save and close the file.

Window Manager Considerations

While this setting works reliably on Windows, macOS, and X11 environments on Linux, behavior may vary on Wayland. Under Wayland, application windows generally cannot dictate their own position on the screen, as window placement is delegated strictly to the Wayland compositor. If you are using Wayland and the window does not center, you must configure centering rules within your specific compositor's settings (such as GNOME, KDE Plasma, or Sway).
