How to Customize the mpv Window Title

This guide explains how to customize the window title text that appears in your operating system's title bar when using the mpv media player. By modifying the title property in the mpv configuration file or passing it directly through the command-line interface, you can dynamically display file names, media metadata, playback time, and custom text using mpv's property expansion system.

Using the mpv Configuration File

To make persistent changes to the title bar, add the title option to your mpv.conf file.

The configuration file is typically found in the following locations depending on your operating system:

  • Linux / macOS: ~/.config/mpv/mpv.conf
  • Windows (Standard): %APPDATA%/mpv/mpv.conf
  • Windows (Portable): mpv/portable_config/mpv.conf (in the same folder as mpv.exe)

Open the mpv.conf file in any plain text editor and add the title directive:

title="${media-title} - mpv"

Save the file and restart mpv for the changes to take effect.

Useful Property Expansion Variables

mpv uses property expansion enclosed in ${property} syntax to inject real-time video information into the title bar. Some of the most useful properties include:

  • ${media-title}: The title tag from the file's metadata, falling back to the filename if no tag exists.
  • ${filename}: The filename of the currently playing media, including the extension.
  • ${playback-time}: The current playback position in HH:MM:SS format.
  • ${duration}: The total length of the media file.
  • ${percent-pos}: The current playback position expressed as a percentage.
  • ${pause}: Returns yes if the media is paused and no if it is playing.

Configuration Examples

Minimalist (Media Title Only)

Shows only the track title or file name without extra software branding:

title="${media-title}"

Media Title with Playback Progress

Displays the title alongside the current timestamp and total duration:

title="${media-title} [${playback-time} / ${duration}]"

Conditional Formatting (Show Pause Status)

You can use conditional syntax (${?property:text}) to show information only when a state is active. This example adds [PAUSED] to the title bar when playback is paused:

title="${?pause==yes:[PAUSED] }${media-title}"

Setting the Title via Command Line

If you want to set a custom title for a single session without editing your configuration file, pass the --title flag when launching mpv from the terminal:

mpv --title="Custom Title - ${filename}" video.mp4
