Change mpv Background Color for Audio Playback

By default, the mpv media player displays a solid black screen whenever you play an audio file that lacks embedded album artwork. You can easily customize this default appearance by modifying mpv's configuration file or passing a command-line flag using the background-color parameter. This guide demonstrates how to set a custom color using hex color codes and ensure the window remains active during audio playback.

1. Locate or Create the Configuration File

To make the color change permanent, edit the mpv.conf file located in your user configuration directory:

  • Linux/macOS: ~/.config/mpv/mpv.conf
  • Windows: %APPDATA%\mpv\mpv.conf or inside the portable_config directory where mpv.exe is located.

If the file does not exist, create a new text file and name it mpv.conf.

2. Add the Background Color Setting

Open mpv.conf in any text editor and add the background-color option. mpv accepts colors in standard #RRGGBB hexadecimal format (or #AARRGGBB if you want transparency).

# Set the background color (e.g., dark slate blue)
background-color="#1e1e2e"

# Keep the window visible for audio-only files
force-window=yes

The force-window=yes option ensures that the mpv window consistently opens and displays your chosen background color even when an audio track has no video track or cover art attached.

3. Test via Command Line

If you want to test the color immediately without saving it to your configuration file, pass the settings directly through the terminal or command prompt:

mpv --force-window=yes --background-color="#282a36" track.mp3

Replace #282a36 with any hex code of your choice, and mpv will render the window with that color whenever an audio file is playing without artwork.
