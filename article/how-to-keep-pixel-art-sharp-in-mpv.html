How to Keep Pixel Art Sharp in mpv

When watching low-resolution pixel art videos or game recordings in mpv, the default upscaling filters introduce unwanted blur and smoothing. This guide explains how to configure mpv to use nearest-neighbor interpolation and conditional profiles, ensuring that low-resolution retro content retains its crisp, sharp pixel edges during playback without manually changing settings every time.

Why Pixel Art Becomes Blurry

By default, mpv uses sophisticated scaling algorithms like Lanczos or Spline36. These algorithms interpolate pixel data to smooth out jagged edges, which is ideal for live-action or high-definition footage. However, for pixel art and retro gaming captures, this smoothing removes the defined, blocky aesthetics of the art. To preserve sharp edges, mpv must be told to duplicate pixels directly rather than blending them.

The Solution: Nearest-Neighbor Scaling

To eliminate blur, set mpv’s scaling algorithm to nearest. This method samples the nearest pixel directly, preserving the original grid structure.

Command Line

You can test nearest-neighbor scaling on a single file from your terminal:

mpv --scale=nearest --cscale=nearest --dscale=nearest video.mp4
  • scale=nearest: Controls luma (brightness) upscaling.
  • cscale=nearest: Controls chroma (color) upscaling.
  • dscale=nearest: Controls downscaling if the window is smaller than the video.

Configuration File (mpv.conf)

To apply this globally, add the following lines to your mpv.conf file:

scale=nearest
cscale=nearest
dscale=nearest
correct-downscaling=no
linear-downscaling=no
sigmoid-upscaling=no

Disabling correct-downscaling, linear-downscaling, and sigmoid-upscaling prevents mpv from performing color-space blending that can soften pixel edges.

Automating with Conditional Profiles

Applying scale=nearest globally will degrade the quality of standard live-action videos. Instead, you can create a conditional profile in mpv.conf that only activates when the video resolution is below a specific threshold:

[pixel-art]
profile-cond=width <= 640 and height <= 480
profile-restore=copy
scale=nearest
cscale=nearest
dscale=nearest
correct-downscaling=no
linear-downscaling=no
sigmoid-upscaling=no

With this block added:

  1. profile-cond checks whether the video width and height are 640x480 or lower.
  2. If true, mpv activates nearest-neighbor scaling.
  3. profile-restore=copy ensures your standard high-quality scalers return when playing higher-resolution files.

Toggling Sharpness on Demand

If you prefer to toggle pixel-art mode manually, map a shortcut key in your input.conf file:

P cycle-values scale nearest spline36 ; cycle-values cscale nearest spline36

Pressing Shift + P during playback will instantly switch between sharp nearest-neighbor rendering and standard smooth scaling.
