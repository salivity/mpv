How to Open mpv on a Specific Monitor

When using a multi-monitor workstation, configuring your media player to launch on a designated display streamlines your workflow. This guide explains how to identify your display indexes and configure mpv to open on a specific monitor automatically using command-line flags or by updating your permanent configuration file.

Step 1: Identify Your Screen Numbers

mpv identifies connected displays using a zero-based index system:

  • 0: Typically your primary or default display.
  • 1: Your secondary display.
  • 2: Your tertiary display, and so on.

To verify how mpv registers your monitors, run the following command in your terminal or command prompt:

mpv --screen=help

This output displays the available display numbers along with their names and resolutions.

Step 2: Set the Monitor via the Command Line

To launch a video on a chosen screen for a single session, use the --screen and --fs-screen flags:

  • --screen=<ID> determines which display the standard mpv window appears on.
  • --fs-screen=<ID> determines which display is used when switching to fullscreen mode.

Example: Launch windowed mode on monitor 1

mpv --screen=1 "video.mp4"

Example: Launch in fullscreen on monitor 1

mpv --fs --fs-screen=1 "video.mp4"

Combining both parameters ensures the player remains on the designated screen whether windowed or fullscreen:

mpv --screen=1 --fs-screen=1 "video.mp4"

Step 3: Set the Monitor Permanently via mpv.conf

To avoid typing the display index every time, define it inside your mpv.conf configuration file.

Locate or Create mpv.conf:

  • Windows: %APPDATA%\mpv\mpv.conf
  • Linux / macOS: ~/.config/mpv/mpv.conf

Add the Configuration:

Open the file in any text editor and add the following lines (replace 1 with your desired display number):

# Specify the display for normal windowed playback
screen=1

# Specify the display for fullscreen playback
fs-screen=1

# Optional: Always open mpv in fullscreen
# fs=yes

Save the file. mpv will now open on your designated monitor whenever a media file is launched.
