How to Change OSD Duration in mpv

By default, on-screen display (OSD) notifications in mpv disappear after only one second (1000 milliseconds), which often makes them difficult to read. You can easily adjust this behavior either permanently by modifying mpv's configuration file or temporarily using a command-line flag. This guide covers how to set the OSD message duration to any length of time that fits your viewing preferences.

Adjusting Duration via the Configuration File

To permanently change the OSD duration, add the osd-duration setting to your mpv.conf configuration file. The value is defined in milliseconds (for example, 3000 equals 3 seconds).

  1. Locate or create your mpv.conf file in the appropriate directory:

    • Linux & macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config folder if using a portable build)

  2. Open mpv.conf in a text editor and add the following line:

    osd-duration=3000

  3. Save the file and restart mpv. All standard OSD status messages, such as volume changes and seeking indicators, will now stay on screen for the specified amount of time.

Adjusting Duration via the Command Line

If you want to test a value or change the duration for a single session without editing your configuration file, pass the --osd-duration flag directly when launching mpv:

mpv --osd-duration=2500 video.mp4

Replace 2500 with your desired duration in milliseconds.
