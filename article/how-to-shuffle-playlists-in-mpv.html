How to Shuffle Playlists in mpv

mpv includes built-in functionality to shuffle items in a playlist without requiring external plugins or user scripts. You can randomize playback order directly from the terminal, permanently enable shuffling through the configuration file, or trigger a shuffle dynamically during active playback using keybindings.

Shuffling via the Command Line

To randomize a playlist or a folder of media files upon launch, use the --shuffle flag:

mpv --shuffle /path/to/playlist.m3u

This also works with directories or wildcards:

mpv --shuffle /path/to/music/*

When applied, mpv shuffles the playlist order into pseudo-random order before starting playback.

Enabling Shuffle by Default

To ensure mpv always shuffles playlists whenever media is loaded, add the setting to your mpv.conf file (located in ~/.config/mpv/ on Linux/macOS or %APPDATA%/mpv/ on Windows):

shuffle=yes

With this line active, any multi-file queue or loaded playlist will automatically play in random order.

Shuffling During Playback

If a playlist is already playing in sequential order, you can shuffle it dynamically using the internal playlist-shuffle command.

To assign this action to a key, open or create your input.conf file in the same configuration directory and add a keybinding:

ctrl+s playlist-shuffle

Pressing Ctrl+S during playback will immediately randomize the remaining queue.

You can also restore the original playlist order by binding the unshuffle command:

ctrl+u playlist-unshuffle

Alternatively, you can open the built-in mpv console during playback (typically by pressing the grave accent/tilde key `) and type playlist-shuffle followed by Enter to randomize the queue immediately.
