Get mpv Playback Duration via IPC in Bash

Controlling the mpv media player programmatically allows you to automate media workflows and extract real-time playback metrics. This guide demonstrates how to interact with mpv's Inter-Process Communication (IPC) JSON interface using a Bash script, send commands across a UNIX socket using tools like socat, and parse the output to retrieve the current playback duration.

1. Enable mpv IPC Server

To communicate with mpv, launch it with the --input-ipc-server flag, defining a path to a UNIX socket:

mpv --input-ipc-server=/tmp/mpvsocket /path/to/video.mp4

Alternatively, add input-ipc-server=/tmp/mpvsocket to your ~/.config/mpv/mpv.conf file to enable the IPC server automatically on every run.

2. The IPC JSON Request

mpv accepts commands formatted as JSON-RPC over the socket. To get the total duration of the file currently playing, query the duration property using the get_property command:

{ "command": ["get_property", "duration"] }

Note: If you need the current elapsed playback time instead of total length, replace "duration" with "time-pos".

3. Query the Socket Using Bash

You can use socat to pipe JSON data into the socket and jq to parse the resulting JSON response.

Install the prerequisites on Debian/Ubuntu:

sudo apt-get install socat jq

Run a one-liner to query the property:

echo '{ "command": ["get_property", "duration"] }' | socat - /tmp/mpvsocket | jq -r '.data'

4. Complete Bash Script Example

Save the following code as get_duration.sh:

#!/usr/bin/env bash

SOCKET="/tmp/mpvsocket"

# Check if socket exists
if [ ! -S "$SOCKET" ]; then
    echo "Error: mpv IPC socket not found at $SOCKET"
    exit 1
fi

# Send JSON command to mpv socket and capture response
RESPONSE=$(echo '{ "command": ["get_property", "duration"] }' | socat - "$SOCKET" 2>/dev/null)

# Extract the value from the JSON response
DURATION=$(echo "$RESPONSE" | jq -r '.data')

# Check if a valid duration was returned
if [ "$DURATION" = "null" ] || [ -z "$DURATION" ]; then
    echo "Playback duration unavailable (no file playing or property unset)."
    exit 1
fi

# Format output (rounded to 2 decimal places)
printf "Total Duration: %.2f seconds\n" "$DURATION"

Make the script executable and run it:

chmod +x get_duration.sh
./get_duration.sh
