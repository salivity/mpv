mpv hwdec-codecs Option Explained

This article explains the function and practical usage of the hwdec-codecs setting in the mpv media player configuration. You will learn how this option controls hardware-accelerated video decoding, why restricting hardware decoding to specific codecs is useful, and how to properly configure the setting within your mpv.conf file.

What Is hwdec-codecs?

The hwdec-codecs option acts as an allowlist for hardware-accelerated video decoding in mpv. While the primary hwdec option tells mpv which hardware decoding API to use (such as vaapi, nvdec, or d3d11va), hwdec-codecs determines which video formats are permitted to use that hardware acceleration.

If a video's codec is included in the hwdec-codecs list, mpv attempts to offload decoding to your GPU. If the codec is not on the list, mpv bypasses hardware acceleration and falls back to software decoding using the CPU, even if hwdec is actively enabled.

Default Behavior

By default, mpv restricts hardware acceleration to a safe list of modern, widely supported codecs. Depending on the version of mpv, the default list typically includes:

  • h264
  • vc1
  • hevc
  • vp9
  • av1

Because of this default allowlist, older codecs such as MPEG-2 or MPEG-4 (DivX/Xvid) generally decode on the CPU unless explicitly added.

Why Use hwdec-codecs?

There are several scenarios where adjusting hwdec-codecs is beneficial:

  1. Avoiding Buggy Driver Implementations: Some GPU drivers claim support for specific formats but exhibit stability issues, color corruption, or playback stuttering during hardware playback. Limiting hwdec-codecs allows you to disable hardware decode for the problematic format while keeping it active for others.
  2. Handling 10-Bit H.264 (Hi10P): Most hardware decoders do not support 10-bit H.264 (commonly used in anime releases). Attempting hardware decode on these files can cause playback failures. While mpv usually detects profile incompatibilities automatically, restricting codecs ensures safe fallbacks.
  3. Saving Power on Older Codecs: Modern CPUs decode standard definition or lightweight codecs (like MPEG-2 or standard H.264) with negligible CPU utilization. You may choose to reserve GPU decoding strictly for demanding formats like 4K HEVC or AV1.
  4. Enabling All Supported Codecs: If you want mpv to attempt hardware decoding on any video format your GPU supports, you can bypass the default whitelist entirely.

Configuration Syntax and Examples

You configure this option either through the command line or inside your mpv.conf file.

To allow hardware decoding only for HEVC and AV1:

hwdec=auto-safe
hwdec-codecs=hevc,av1

To enable hardware decoding for all codecs supported by your hardware:

hwdec=auto-safe
hwdec-codecs=all

To use a standard set of modern formats (H.264, HEVC, VP9, and AV1):

hwdec=auto-safe
hwdec-codecs=h264,hevc,vp9,av1

Multiple codecs must be separated by commas without spaces. When paired with hwdec=auto or hwdec=auto-safe, hwdec-codecs gives you granular control over hardware resource utilization during playback.
