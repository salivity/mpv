How to Pause mpv Automatically When Minimized

You can easily configure the mpv media player to pause playback automatically when its window is minimized by using a lightweight Lua script. While mpv does not have a single toggle in its default configuration file for this behavior, its internal scripting engine can track window states and trigger actions immediately. Below is a straightforward guide on setting up the script across Windows, macOS, and Linux systems.

Step 1: Locate the Scripts Directory

mpv looks for custom Lua scripts in a designated scripts subfolder inside your primary mpv configuration directory. Navigate to the path corresponding to your operating system:

  • Windows: %APPDATA%\mpv\scripts\ (typically C:\Users\<YourUsername>\AppData\Roaming\mpv\scripts\)
  • Linux: ~/.config/mpv/scripts/
  • macOS: ~/.config/mpv/scripts/

Note: If the scripts folder does not exist, create it manually inside your main mpv directory.

Step 2: Create the Lua Script

Inside the scripts folder, create a new text file and name it auto-pause-minimize.lua.

Open the file in any text editor and paste the following code:

local was_paused = false

mp.observe_property("window-minimized", "bool", function(name, minimized)
    if minimized then
        was_paused = mp.get_property_bool("pause", false)
        if not was_paused then
            mp.set_property_bool("pause", true)
        end
    else
        if not was_paused then
            mp.set_property_bool("pause", false)
        end
    end
end)

How the Script Works

  • Detects Minimize Events: The window-minimized property monitors the state of the mpv window.
  • Smart Resume: The script checks whether the video was already paused before minimization. If you paused it manually, it stays paused when restored. If it was playing, it pauses upon minimization and resumes automatically when unminimized.

If you prefer the video to stay paused even after you restore the window, replace the code with this simpler snippet:

mp.observe_property("window-minimized", "bool", function(name, minimized)
    if minimized then
        mp.set_property_bool("pause", true)
    end
end)

Step 3: Save and Test

  1. Save the .lua file and close the editor.
  2. Launch mpv and open any video file.
  3. Minimize the window to verify that playback pauses instantly.

Platform Compatibility Notes

  • Windows: Fully supported natively through standard window hooks.
  • Linux (X11): Works automatically with most desktop environments and window managers.
  • Linux (Wayland): Depending on your compositor (e.g., GNOME or KDE), the window-minimized property might not be reported reliably due to Wayland's security isolation. If this occurs, you may need to run mpv via XWayland by adding x11 to your gpu-context settings.
