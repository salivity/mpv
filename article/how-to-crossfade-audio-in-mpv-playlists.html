How to Crossfade Audio in mpv Playlists

This article explains whether mpv supports crossfading between audio tracks, how the player natively handles transitions, and the available methods to achieve overlapping playback. While mpv does not offer a native, single-command crossfade feature, you can achieve track crossfading through specialized user scripts, multi-instance setups, or pre-processing filters.

Native mpv Capabilities: Gapless vs. Crossfade

By default, mpv does not support true audio crossfading, where the end of one track fades out while the next track simultaneously fades in over it.

mpv natively supports gapless audio playback using the --gapless-audio=yes flag (which is enabled by default). Gapless playback ensures that consecutive tracks play without pauses, clicks, or silence between them. However, gapless playback remains strictly sequential; mpv terminates the audio stream of the outgoing track before decoding and playing the incoming track.

Workarounds to Enable Crossfading in mpv

Because mpv's single-instance architecture only decodes one audio file at a time, achieving an actual crossfade requires external methods or scripting.

1. Using Lua Scripts with Multi-Instance Control

The most common way to crossfade in mpv is by using community-developed Lua scripts that leverage mpv’s Inter-Process Communication (IPC).

  • These scripts run a secondary, hidden instance of mpv in the background.
  • When the primary track approaches its end, the script launches the next track in the secondary instance, gradually raising its volume while lowering the volume of the primary instance.
  • Once the transition is complete, playback control switches back to the primary instance.

To use this method, search for user-made scripts like mpv-crossfade on script repositories such as GitHub and place the .lua file into your ~~/scripts/ directory.

2. Pre-mixing Playlists with FFmpeg

If dynamic playback control is not required, you can use FFmpeg (the multimedia framework behind mpv) to stitch and crossfade tracks into a single continuous file before playback:

ffmpeg -i track1.mp3 -i track2.mp3 -filter_complex acrossfade=d=5:c1=tri:c2=tri output.mp3

This command uses the acrossfade audio filter to blend two files with a 5-second transition. The resulting file can then be played smoothly in mpv.

Better Alternatives for Crossfading Audio

If automatic, on-the-fly crossfading without custom scripts is essential for your workflow, dedicated music players provide this functionality natively:

  • MPD (Music Player Daemon): Supports native crossfading between playlist items using the crossfade configuration setting.
  • Clementine / Strawberry: Full-featured desktop music players with built-in fading preferences.
  • cmus: A lightweight terminal-based audio player that supports crossfading out of the box.
