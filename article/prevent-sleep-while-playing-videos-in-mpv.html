Prevent Sleep While Playing Videos in MPV

By default, the mpv media player includes features to prevent your display from turning off and your operating system from entering sleep mode during video playback. If your system continues to fall asleep while media is running, you can resolve the issue by enabling the native screensaver inhibitor in mpv's configuration file or through the command line. This guide provides the exact configuration settings and file locations needed to keep your computer awake across Windows, macOS, and Linux.

Edit the mpv Configuration File

To permanently stop your computer from sleeping during playback, add the stop-screensaver option to your mpv.conf configuration file.

  1. Locate or create the mpv.conf file on your system:

    • Linux and macOS: ~/.config/mpv/mpv.conf
    • Windows: %APPDATA%\mpv\mpv.conf (or inside the portable_config directory if using a portable installation)

  2. Open the file in any plain text editor.

  3. Add the following line:

    stop-screensaver = yes

  4. Save and close the file.

Using the Command-Line Option

If you run mpv from a terminal or through custom application launchers, you can pass the flag directly at runtime without modifying the configuration file:

mpv --stop-screensaver=yes "path/to/your/video.mp4"

Platform-Specific Troubleshooting

  • Linux (X11 / Wayland): mpv communicates with your desktop environment via DBus (such as org.freedesktop.ScreenSaver or platform-specific power management protocols). If your system still sleeps, ensure that your desktop environment has an active notification daemon or screensaver service running that implements standard FreeDesktop idle-inhibition protocols. Under minimal window managers like i3 or bspwm, you may need a standalone utility such as xss-lock or caffeine.
  • Windows: The stop-screensaver directive uses the Windows API call SetThreadExecutionState to inform the system that display and system states are in use. Ensure that aggressive third-party battery-saver applications are not overriding active Windows execution states.
  • macOS: mpv utilizes macOS power assertions via IOPMAssertionCreateWithName. This prevents both system idle sleep and display dimming automatically as long as video rendering is active.
