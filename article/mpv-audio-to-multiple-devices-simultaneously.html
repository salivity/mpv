MPV Audio to Multiple Devices Simultaneously

While mpv cannot natively split an audio stream across multiple hardware outputs with a single standalone command, it can easily output audio to multiple devices simultaneously by relying on your operating system's sound architecture or virtual audio routing. By combining mpv's device selection flag with tools in Linux, Windows, or macOS, you can mirror audio to headphones, external speakers, and HDMI displays without latency issues.

Understanding mpv Audio Routing

The mpv media player relies on underlying audio backends (such as PulseAudio, PipeWire, WASAPI, or CoreAudio) and limits its --audio-device parameter to a single target. Because mpv does not duplicate output streams internally across hardware interfaces, multi-device playback requires creating a unified virtual device at the operating system level, which mpv then targets as its single output.

How to Set It Up by Operating System

Linux (PulseAudio or PipeWire)

Linux makes multi-device output straightforward using combined sinks.

  1. Create a Combined Sink: Run the following command in your terminal to create a virtual device that mirrors audio to all active outputs: 
    pactl load-module module-combine-sink sink_name=combined
  2. Target the Sink in mpv: Launch mpv with the combined sink selected: 
    mpv --audio-device=pulse/combined video.mp4

Alternatively, if you use PipeWire with a graphical patchbay like qpwgraph or Helvum, you can launch mpv normally and drag output nodes to multiple audio device sink nodes in real time.

Windows (WASAPI)

Windows does not natively offer combined outputs inside mpv, but you can achieve this using system settings or virtual audio mixers:

  1. Using Stereo Mix:
    • Open the classic Sound Control Panel (mmsys.cpl).
    • Go to the Recording tab, right-click, enable Show Disabled Devices, and enable Stereo Mix.
    • Open Stereo Mix Properties, go to the Listen tab, check Listen to this device, and select your secondary audio device.
    • Set your primary audio device as the default in Windows, and mpv will play to both.
  2. Using Voicemeeter:
    • Install a virtual mixer like Voicemeeter.
    • Select your hardware outputs as A1 and A2.
    • List mpv audio devices via command prompt: 
      mpv --audio-device=help
    • Pass the Voicemeeter virtual input to mpv: 
      mpv --audio-device=wasapi/{Device-ID} video.mp4

macOS (CoreAudio)

macOS includes native support for combined audio endpoints through the Audio MIDI Setup utility:

  1. Open Audio MIDI Setup from Applications > Utilities.
  2. Click the + icon at the bottom-left corner and select Create Multi-Output Device.
  3. Check the boxes next to the audio devices you want to use simultaneously.
  4. Run mpv --audio-device=help in Terminal to find the name of the newly created device.
  5. Launch mpv targeting that device: 
    mpv --audio-device='coreaudio/Multi-Output Device' video.mp4

Making the Setting Permanent in mpv

Once you have configured a virtual multi-device output, you can make it the default for all playback sessions by adding the following line to your mpv.conf file:

audio-device="your-combined-device-name"

This configuration ensures mpv automatically routes sound to all your chosen playback devices every time a media file is opened.
