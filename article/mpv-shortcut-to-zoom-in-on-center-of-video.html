mpv Shortcut to Zoom In on Center of Video

This guide explains how to set up custom keyboard shortcuts in the mpv media player to zoom smoothly in and out from the center of a video. By adding bindings for the video-zoom property to your input.conf file, you can instantly control zoom levels and reset your view to default settings during playback.

Step 1: Locate or Create input.conf

mpv stores custom keyboard shortcuts in a plain text file named input.conf. Depending on your operating system, navigate to the following directory:

  • Windows: %APPDATA%\mpv\input.conf (or inside a portable_config folder in the directory where mpv.exe is located)
  • Linux: ~/.config/mpv/input.conf
  • macOS: ~/.config/mpv/input.conf

If the input.conf file does not exist in the folder, create a new text file and name it input.conf.

Step 2: Add the Zoom Keybindings

Open input.conf in any plain text editor (such as Notepad, TextEdit, or VS Code) and add the following lines:

# Zoom in toward the center
+ add video-zoom 0.1

# Zoom out from the center
- add video-zoom -0.1

# Reset zoom and center the frame
BS set video-zoom 0 ; set video-pan-x 0 ; set video-pan-y 0

How the Commands Work

  • add video-zoom 0.1: Increases the zoom level. By default, mpv scales the video relative to the center of the display. Using 0.1 increases the magnification step by step, but you can change this value to alter zoom sensitivity (for example, 0.2 for faster zooming).
  • add video-zoom -0.1: Decreases the zoom factor back toward normal magnification.
  • set video-zoom 0 ; set video-pan-x 0 ; set video-pan-y 0: Bound to Backspace (BS in mpv), this resets the zoom factor back to 100% and resets any accidental horizontal or vertical panning back to absolute center.

Step 3: Save and Test

Save the input.conf file and launch a video using mpv. Press the + key (or your assigned key) to zoom into the center of the screen, - to zoom out, and Backspace to return the video to its original dimensions. Changes to input.conf take effect immediately upon restarting mpv or when opening a new video file.
