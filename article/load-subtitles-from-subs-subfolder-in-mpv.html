Load Subtitles from Subs Subfolder in mpv

This guide explains how to configure the mpv media player to automatically detect and load subtitle files located within a subfolder named "subs" inside your video directory. By adding a single directive to your mpv configuration file or using a command-line flag, you can keep your media folders organized without needing to manually drag and drop subtitle tracks during playback.

Step 1: Locate or Create the mpv Configuration File

mpv uses a configuration file named mpv.conf to store default playback preferences. Depending on your operating system, this file is located in the following directories:

  • Windows: %APPDATA%\mpv\mpv.conf (typically C:\Users\<Username>\AppData\Roaming\mpv\mpv.conf)
  • Linux: ~/.config/mpv/mpv.conf
  • macOS: ~/.config/mpv/mpv.conf

If the folder or the mpv.conf file does not exist, create them manually.

Step 2: Add the Subtitle Path Option

Open mpv.conf in any standard text editor and add the following line:

sub-file-paths=subs

This instruction tells mpv to search for subtitle files in a subfolder named subs relative to the directory of the video being played.

If you also want mpv to search for other common variations such as sub or subtitles, you can separate multiple folder names with colons on Linux/macOS or semicolons on Windows (mpv also accepts colons universally):

sub-file-paths=sub:subs:subtitles

Step 3: Enable Fuzzy Matching (Recommended)

To ensure mpv loads subtitle files even if their filenames do not match the video filename character-for-character, add the following line directly below the path setting:

sub-auto=fuzzy

Step 4: Save and Test

  1. Save and close the mpv.conf file.
  2. Place a video file in a directory alongside a subfolder named subs.
  3. Place your subtitle file (.srt, .vtt, .ass, etc.) inside that subs folder.
  4. Play the video in mpv. The subtitle track will be automatically detected and loaded.

Alternative: Command-Line Usage

If you prefer not to modify the configuration file globally, pass the option directly when launching mpv from the terminal or command prompt:

mpv --sub-file-paths=subs "video.mkv"
