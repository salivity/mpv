Force mpv to Open at 100% Native Resolution

By default, the mpv media player dynamically resizes its playback window depending on your display dimensions and system scaling, often shrinking large 4K files or scaling up low-resolution clips. This guide explains how to configure mpv to bypass automatic window fitting and consistently display every video file at its exact 100% native pixel dimensions.

The Solution: Update mpv.conf

To enforce a strict 1:1 native resolution window every time mpv launches, add the following lines to your mpv.conf configuration file:

# Force the initial window size to 100% of the video's native resolution
window-scale=1

# Disable automatic downsizing for videos larger than your screen
autofit-larger=none

# Disable automatic upsizing for videos smaller than minimum screen thresholds
autofit-smaller=none

Where to Find or Create mpv.conf

Depending on your operating system, place the configuration lines in the appropriate directory:

  • Windows: %APPDATA%\mpv\mpv.conf (or inside portable_config\mpv.conf if using the portable version).
  • Linux: ~/.config/mpv/mpv.conf
  • macOS: ~/.config/mpv/mpv.conf

If the folder or the mpv.conf file does not exist yet, create them manually.

Handling High-DPI Displays (Retina / 4K Monitors)

On systems with OS-level display scaling enabled (such as macOS Retina displays or Windows scaled displays at 125%, 150%, or 200%), mpv may treat the video as scaled pixels rather than true physical device pixels.

To force mpv to map video pixels directly to physical screen pixels on high-DPI monitors, add this additional line:

no-hidpi-window-scale

Running from the Command Line

If you want to test the behavior without permanently changing your configuration file, pass the parameters directly through your terminal:

mpv --window-scale=1 --autofit-larger=none --autofit-smaller=none video.mp4
